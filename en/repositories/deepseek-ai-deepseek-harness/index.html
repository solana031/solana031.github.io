Purpose

DeepSeek Harness (`dsh`) is an open-source agent harness developed by DeepSeek AI. It is built on an everything-is-a-plugin architecture and powered by Cordis, whose design is described in the paper _A Programming Paradigm for Spatiotemporal Composability_.

Requirements and Setup

The project is currently in a developer preview stage and is iterating rapidly, meaning there will be compatibility-breaking changes. Users should review the safety notices before running the project. Basic usage requires Node.js to be installed on your environment.

Installation

You can run the application directly through npm or from a source repository checkout using the documented commands:

npx @deepseek-ai/dsh web

Alternatively, to run from source:

git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web

Usage

The start command initializes the Web UI at `http://127.0.0.1:3080` by default and opens it in your default browser. For SSH launches, it prints the host URL instead since the remote client manages port forwarding. Pass `--no-open` to run the server without launching a local browser window.

Limitations

Because DeepSeek Harness is in developer preview, breaking changes are expected during rapid iterations. Users must pay attention to security notices and dependency updates.

Alternatives as Editorial Comparison

Compared to monolithic agent frameworks, DeepSeek Harness provides a modular, plugin-centric approach powered by Cordis, allowing for advanced spatiotemporal composability across components.
