Purpose

Whiteboard Animation VI is a local, Gradio-backed application built to transform illustrated images into whiteboard-style animations. It combines subject-first coloring, color clustering in Lab color space, ink-aware region boundaries, and moving photographic hands. It prioritizes the appearance of primary characters before filling in the background and exports the final output directly to MP4 format.

Requirements and Environment

The project requires a 64-bit installation of Python 3.11 or 3.12 on Windows systems. For NVIDIA CUDA rendering acceleration, a compatible NVIDIA driver is required alongside the optional `PyNvVideoCodec` package if NVENC encoding is desired. Standard CPU exports utilize `libx264` and require FFmpeg to be available in the system's `PATH`.

Installation

Run the following PowerShell commands from the repository directory to set up the virtual environment and install dependencies:

py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip

To enable NVIDIA CUDA GPU acceleration support, install the appropriate PyTorch components and GPU requirements:

.\.venv\Scripts\python.exe -m pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r requirements-gpu.txt

For CPU-only workflows, execute the following:

.\.venv\Scripts\python.exe -m pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

Additionally, the required subject segmentation model checkpoint must be downloaded explicitly before utilizing segmentation features:

.\.venv\Scripts\python.exe scripts\download_model.py

Usage and Local Execution

You can launch the local interface by executing the `start.bat` batch script or via PowerShell:

.\start.ps1
.\start.ps1 -Port 7861

If you prefer running the server in the foreground with console logging:

.\.venv\Scripts\python.exe app.py --port 7860 --open --log

You can also integrate rendering directly inside Python scripts:

import numpy as np
from PIL import Image
from handdraw.settings import Settings
from handdraw.render import render_video

image = np.asarray(Image.open("input.png").convert("RGBA"))
settings = Settings(mode="e", duration=10, draw_percent=70, ink_percent=45)
video_path, report = render_video(image, settings)

Advantages

- Foreground separation using ISNet (SkyTNT Anime Segmentation) ensures characters remain visible early in the sequence.

- Optimized routing reduces unnecessary travel between strokes while strictly preserving subject and color order.

- Built-in caching retains recent image plans to speed up adjustments to timing and hand settings.

- Private local interface disables public sharing and Gradio analytics, binding strictly to localhost (`127.0.0.1`).

Limitations

- Network operations for downloading model checkpoints enforce rigid timeouts with no automatic retries.

- Sample illustrations included in the official documentation carry separate licensing terms and require verification prior to redistribution.

- Rendering jobs are processed serially with a pending queue size capped at a maximum of eight jobs.

Editorial Comparison and Alternatives

Unlike cloud-based whiteboard animation platforms that impose rendering quotas or recurring subscription fees, Whiteboard Animation VI provides a fully local, open-source approach leveraging local hardware acceleration (CUDA/NVENC or CPU). Other commercial or cloud alternatives provide significantly less granular control over ink-aware stroke segmentation and automated color cluster ordering.
