Purpose and use case

This document provides an independent editorial guide to getting started with Postiz for centralized digital content scheduling. A typical use case involves planning weekly posts across multiple social platforms from a single web interface or through connected artificial intelligence agents.

What it is and how it works

Postiz is a social media management platform designed to schedule, automate, and analyze content. Its architecture is built upon a monorepo managed with pnpm workspaces, utilizing modern web technologies such as NextJS for the React user interface, NestJS for the backend, Prisma ORM configured by default with PostgreSQL, Temporal for workflow orchestration, and Resend for email notifications.

The system operates through a clear separation between the web interface and local or cloud infrastructure. In a self-hosted installation, the software runs on your own server executing containers or services configured via environment variables, communicating directly with social platforms through official OAuth authentication flows without storing third-party API keys on intermediary servers.

When to use it

- When you need to manage and schedule posts centrally across networks such as X, LinkedIn, YouTube, Instagram, TikTok, or Reddit.

- When you are looking for an open-source, self-hostable alternative to maintain complete control over your marketing data under the AGPL-3.0 license.

- When you want to integrate content automation with workflow platforms like n8n, Make.com, or AI agents via the Model Context Protocol (MCP).

What you need

To run the open-source version of Postiz on your own infrastructure, you need a server supporting Docker or deployment tools such as Coolify or Railway. Additionally, you must have compatible databases (like PostgreSQL), Redis for queues, and configured storage. To access advanced AI features or publish on specific platforms, you must provide your own API keys from providers like OpenAI or register your own developer applications on the respective social networks.

Where to get it

The official source code and application packages are located in the `gitroomhq/postiz-app` GitHub repository. Official documentation is available at docs.postiz.com and the commercial website at postiz.com.

Installation

Local installation depends on your chosen infrastructure (Docker, VPS, or platforms like Coolify). Because specific container configuration steps and environment variables vary and are not fully detailed in the quick reference package beyond following the official quick start guide, it is recommended to consult the deployment documentation at docs.postiz.com or let a language assistant help configure the necessary environment variables for PostgreSQL, Redis, and storage.

First use step by step

1. Deploy your Postiz instance on your local server or access Postiz Cloud via platform.postiz.com.

2. Open the web interface of the application in your web browser.

3. Set up your user account and log in to the main dashboard.

4. Connect your social media accounts using the official OAuth authentication flows provided by each platform.

5. Create your first post by selecting the target networks, writing the text or adding media content, and choosing a date and time to schedule it.

Common errors and how to solve them

- **Social media authentication failure:** Ensure you have correctly configured your own developer credentials if using the self-hosted version, or verify that OAuth redirects are allowed.

- **Database connection issues:** Check that the environment variables for PostgreSQL and Redis are defined correctly and that the container services are running.

- **Security vulnerabilities:** Upgrade immediately to recent versions (such as v2.25.3 or higher) to resolve known security advisories such as PSA-2026-E9AHFV and PSA-2026-YT2HMH.

Limitations

- The self-hosted version requires you to create your own developer applications on platforms like Meta, YouTube, or TikTok, which may take several days depending on each provider's approval.

- Maintenance, backups, security patches, and image updates in the open-source edition are solely the user's responsibility.

- AI quotas depend on the API keys you provide yourself in the self-hosted version.

Alternatives and how it compares

- **Postiz Cloud:** Offers a fully managed experience with pre-approved applications for every channel and included monthly quotas, compared to the requirement of setting up your own infrastructure in the open-source edition.

- Other commercial social management tools like Buffer or Hootsuite offer closed SaaS platforms, whereas Postiz stands out for its open-source approach under AGPL-3.0 and its compatibility with AI agents.

FAQ

**Does Postiz store my social media credentials?**

No. Postiz uses official OAuth flows from each platform and never requests or stores users' API keys or access tokens on hosted servers.

**What is the difference between Postiz Cloud and the open-source version?**

Both provide the same core features, but Cloud is managed by the provider with approved apps and plan-based subscriptions, while the open-source version is free under AGPL-3.0 and requires your own infrastructure.

**What license does the project use?**

Source code available in the official repository is distributed under the AGPL-3.0 license.

**What is the price of the self-hosted edition?**

The open-source software is free (AGPL-3.0); you only pay for the infrastructure costs you use to host it.

Editorial assessment

Postiz is an excellent solution for developers, technical teams, and digital marketers who want an advanced social scheduling tool with automation and artificial intelligence capabilities, while maintaining total control over their data through a self-hosted architecture. Users without technical experience in server administration or those who prefer a traditional commercial SaaS solution without the need to configure social media developer apps should skip this tool.
