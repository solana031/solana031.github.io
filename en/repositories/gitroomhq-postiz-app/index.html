Purpose

Postiz is a social media management platform built for scheduling, automating, and analyzing content across multiple channels. It integrates agentic AI features and supports automation platforms such as N8N, Make.com, and Zapier through its public API and SDKs.

Requirements and Setup

The project utilizes a Pnpm workspaces monorepo structure, NextJS for the frontend, NestJS for the backend, Prisma as the default ORM for PostgreSQL, Temporal for workflows, and Resend for email notifications.

To run the self-hosted edition, users must deploy the application using Docker, Coolify, Railway, or any standard VPS, while manually configuring environment variables, PostgreSQL, Redis, and storage.

Usage

Users can manage content using calendar views to schedule posts, collaborate with team members, set up RSS auto-posting, and connect AI agents and agentic surfaces (including ChatGPT, Claude, Cursor, MCP, and CLI tools).

Advantages

- Supports a vast array of social channels and communities (Instagram, YouTube, LinkedIn, X, TikTok, Discord, Mastodon, Bluesky, and more).

- Delivers identical core features across both the managed cloud offering and the open-source self-hosted edition.

- Unlimited channels, monthly posts, and team members on the self-hosted version.

- Native connectivity for AI workflows and third-party automation tools.

Limitations

- Infrastructure maintenance, security patches, backups, and updates are the sole responsibility of the user in self-hosted deployments.

- Setting up developer apps on third-party social platforms (such as Meta, YouTube, or TikTok) requires manual approval workflows that can take weeks.

- Advanced AI features require users to bring their own API keys and configure quotas manually in self-hosted setups.

Alternatives and Editorial Comparison

Key differences outline the choice between deployment models:

- **Postiz Cloud:** Fully managed SaaS subscription with a 7-day free trial, pre-approved platform apps, and bundled AI quotas.

- **Postiz Open-Source (Self-Hosted):** Free forever under the AGPL-3.0 license; users pay strictly for their own infrastructure and manage their own developer app credentials.

License and Pricing

The source code in this repository is provided under the AGPL-3.0 license. Verified official pricing for Postiz Cloud depends on subscription tiers available on their website, whereas verified pricing for self-hosting is unavailable beyond user-managed infrastructure costs.
