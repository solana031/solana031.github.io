html-anime Guide: Creating Code-Based Anime Art with AI Agents

Explore html-anime, a tool that turns scene prompts into shot sheets so coding agents can draw animations entirely in HTML, without relying on traditional video models.

Purpose

The **html-anime** project allows you to turn a scene prompt or description into a detailed shot sheet. Instead of relying on traditional video generation models, the workflow delegates visual creation to a coding agent (such as Claude, Codex, Cursor, or Grok). This agent interprets the sheet and draws the frames using pure HTML code along with the HyperFrames renderer.

Requirements and Setup

To get the repository running locally, make sure you have Git and Node.js available on your system. Initial setup is performed using standard repository cloning commands:

git clone https://github.com/blixvip/html-anime.git
cd html-anime

Additionally, because the system requires the folder to be served locally via HTTP for sheets to execute properly in the browser, you can spin up a quick server:

python -m http.server

*(Note: Opening `index.html` directly as a file will show an instruction indicating that the sheet will not run until the folder is served).* You can also build a brief directly in Node without dependencies using the built-in compilation harness.

Usage

You can generate shot sheets via the browser interface or programmatically compile briefs using Node.js:

import { compileBrief } from "./harness/compile.js";

const sheet = compileBrief({
  logline: "On a roof in the rain, a red moon opens and a line of light falls.",
  seconds: 8,
  aspect: "16:9",
  script: "indigo",
  dialogue: "The rain hid the sound of the blade.",
});
console.log(sheet.ok ? sheet.markdown : sheet.error);

To test runtime parameters and ensure shot constraints are met, run the test suite:

npm test

And to preview or lint the reference film:

cd films/roof
npx hyperframes preview

Advantages

- **No video models required:** Bypasses heavy, traditional generative video neural networks.

- **Strict rule-based enforcement:** Agents must abide by strict constraints regarding shot timing, drawing counts, restricted color hexes, and verbatim dialogue.

- **Multi-agent support:** Out-of-the-box rule sets for Claude Code, Codex, Cursor, and Grok.

Limitations

- The project folder must be served via a local web server; opening files directly will restrict execution.

- Results depend heavily on the coding agent's ability to render complex HTML artwork accurately.

- Shot durations are strictly restricted to predetermined runtimes (8, 12, or 20 seconds).

Editorial Comparison and Alternatives

Compared to black-box diffusion video generators that output opaque media files, this approach favors source-code transparency by constructing stylized HTML and web-based artwork. As an alternative to tools like Sora or Runway—which generate pixels directly via massive neural networks—html-anime offers programmatic and modular control over animation elements through software development agents.
