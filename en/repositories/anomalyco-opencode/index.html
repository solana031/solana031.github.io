Purpose

OpenCode is an open-source AI coding agent designed to assist with software development tasks through a terminal user interface and a dedicated desktop application. It interacts directly with codebases using specialized agent capabilities.

Requirements

Depending on the chosen installation method, requirements include a compatible package manager such as npm, Homebrew, pacman, paru, mise, or nix, or a bash-compatible terminal for the automatic installation script.

Installation

Several installation paths are officially documented depending on your operating system:

curl -fsSL https://opencode.ai/v2/install | bash
npm i -g @opencode/cli@latest
brew install anomalyco/tap/opencode-v2
brew install opencode
sudo pacman -S opencode
paru -S opencode-beta
mise use -g opencode
nix run github:anomalyco/opencode

For macOS desktop installation via Homebrew:

brew install --cask opencode-desktop

Usage and Agents

OpenCode includes built-in agents that can be toggled using the `Tab` key:

- **build**: The default, full-access agent for general development work.

- **plan**: A read-only agent for analysis and code exploration, denying file edits by default and prompting for confirmation before running bash commands.

Additionally, a **general** subagent handles complex searches and multi-step tasks, which can be invoked using `@general`.

Limitations

Versions older than 0.1.x must be removed prior to installing new updates. The desktop application is currently designated as BETA software.

License and Pricing

OpenCode is released under the MIT license. Verified official pricing information is unavailable in the source package.

Alternatives

As an open-source terminal and desktop coding agent, OpenCode serves as an alternative to proprietary developer assistants, offering distinct multi-agent modes like plan and build.
