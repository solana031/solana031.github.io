Purpose and Use Case

The purpose of this guide is to enable you to create videos programmatically using familiar web technologies like React. A concrete use case is automating the generation of massive promotional videos for an e-commerce platform using dynamic data feeds.

When to Use It

You should use Remotion when you need to generate audiovisual content repeatedly through code or automated systems, rather than relying on traditional graphical user interface video editors.

What You Need

To follow this guide, you need to have Node.js installed on your operating system, along with a functional command-line terminal and internet access to download the necessary dependencies.

Where to Get It

The official project repository and main source code are available on GitHub under the path remotion-dev/remotion, and its official website is hosted at remotion.dev.

Installation

Local installation is performed directly by executing an interactive package runner utility via Node.js in your terminal.

First Use

Open your local terminal and execute the initialization command to set up a new interactive video project workspace.

npx create-video@latest

This command downloads and launches the interactive Remotion setup wizard, generating your initial project file structure in the current directory.

Limitations and License

Remotion has a special license (marked as NOASSERTION in the package metadata) that requires obtaining a company license in certain documented scenarios. Regarding technical constraints, some advanced HTML-in-canvas rendering features have nested support limitations according to the official documentation.

Hosted Access vs. Local Installation

Local installation runs entirely on your own infrastructure using Node.js and the mentioned command-line tools. There is no mandatory centralized proprietary SaaS platform provided by the core project for basic editing, although cloud deployment integrations such as Vercel and AWS Lambda are officially documented.
