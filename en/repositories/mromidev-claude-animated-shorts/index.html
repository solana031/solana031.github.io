Overview and System Architecture

The `mromidev/claude-animated-shorts` repository provides a specialized Claude Code skill for creating 55-to-70-second vertical animated story shorts. According to the upstream repository documentation, the technical approach places 2D characters within a 3D environment rendered using Three.js inside Remotion. The visual pipeline incorporates ink outlines, painted textures, depth-of-field lens blur, and camera motions, paired with synthesized audio featuring march scores, sound effects, and loudness ducking.

Unlike cloud video generation platforms based on AI video models, the entire rendering pipeline runs locally on the user's computer without invoking AI video generators.

Requirements and Installation

The source documentation specifies several system dependencies prior to executing the skill pipeline:

- Node.js

- Python 3

- ffmpeg

- Remotion configured with `@remotion/three`

The setup instructions published in the repository require the following steps:

1. Clone or extract the repository code into `~/.claude/skills/cartoon-3d-short/`.

2. Ensure Node.js, Python 3, ffmpeg, and `@remotion/three` are accessible in the local workspace environment.

3. Assign the environment variable `REMOTION_TMP` to a storage location on a drive with large free space. Each Remotion bundle copies the `public/` directory (around 1.3 GB) into the temporary directory during processing.

Workflow and Execution

Execution is triggered within Claude Code by invoking the registered skill through prompts such as:

Use the cartoon short skill and make a short about …

Following the rules established in `SKILL.md`, Claude processes the topic, generates the script, prepares voice tracks, structures camera and scene shots in `story.ts`, extracts stills, and runs frame-by-frame quality assurance using reference reports before executing the final 2K render and audio mix.

Advantages and Limitations

A clear technical advantage is deterministic programmatic control over scenes and camera trajectories without incurring per-second video generation API fees. Conversely, operational limitations include high local disk throughput demands due to temporary asset duplication (~1.3 GB per build) and dependency on host hardware rendering speeds. Upstream guidelines also mandate that storyline content and voice assets should be original rather than copied from reference materials.

Editorial Comparison and Licensing

Compared to pure diffusion-based video engines like Runway or Pika, this repository uses code-driven rendering via Three.js and Remotion components. The project codebase and documentation are published under the open-source MIT License. Verified pricing details for external APIs or LLM usage are not documented within the official repository files.
