Purpose

MoneyPrinterTurbo is an all-in-one open-source tool designed to automatically generate high-definition short videos. Given a video topic or keyword, the software handles script writing, stock footage matching, subtitle generation, and background music composition, culminating in a ready-to-publish short video suitable for platforms such as TikTok, Instagram, and YouTube Shorts. It provides multiple interaction pathways including AI Agents, a WebUI, an API, and a Command Line Interface (CLI).

Requirements

- **Operating System**: Windows 10, macOS 11.0 or higher, and major Linux distributions.

- **Python**: Python 3.11 or higher is required (Python 3.11 is recommended).

- **Hardware**: A GPU is not strictly mandatory if relying on cloud-based providers. However, a dedicated graphics card with VRAM is recommended if you wish to run local transcription (`faster-whisper`), achieve faster video processing, or execute heavy batch generation tasks.

| Item | Minimum | Recommended | Ideal |

| --- | --- | --- | --- |

| CPU | 4 cores | 6 to 8 cores | 8 cores or higher |

| RAM | 4 GB | 8 GB | 16 GB or higher |

| GPU | Not required | 4 GB VRAM or higher | 8 GB VRAM or higher |

Installation and Setup

The installation steps documented by the source package are outlined below.

### Clone the Repository

git clone https://github.com/harry0703/MoneyPrinterTurbo.git

### Docker Deployment

Ensure Docker Desktop is installed and properly configured, then run:

cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up

### Manual Deployment via uv

It is recommended to use `uv` for managing Python environments and dependencies:

uv python install 3.11
uv sync --frozen

Usage

To launch the WebUI interface, execute the platform-specific script from the project root directory.

On Windows:

.\webui.bat

On macOS or Linux:

sh webui.sh

To run generation purely via the command line without browser requirements:

uv run python cli.py --video-subject "人工智能如何改变日常生活"

Advantages

- End-to-end automation from initial prompt/topic and script writing down to final video export.

- Extensive support for major language model providers and voice synthesis services (such as Edge TTS for free, Azure, OpenAI, Claude, Gemini, DeepSeek, and many others).

- Versatile aspect ratios supported for diverse social media platforms (`9:16`, `16:9`, `1:1`).

- Open-source flexibility with active updates and multiple deployment choices (Docker, WebUI, CLI, API).

Limitations

- Integration with remote commercial AI services or cloud TTS platforms requires valid API credentials and incurs usage fees depending on the provider.

- Local processing tasks such as Whisper-based transcription demand proper system resources and may run slower without a dedicated local GPU.

- File paths on Windows environments must avoid spaces, special characters, and non-ASCII names to prevent execution errors.

Alternatives and Editorial Comparison

- **Traditional Video Editors (e.g., CapCut, Premiere)**: Grant absolute manual control over every frame and timeline element, but lack automated AI script generation and automated media sourcing features.

- **Cloud SaaS Video Generators (e.g., InVideo, Pictory)**: Easier for non-technical users to jump into immediately, but typically enforce strict proprietary pricing subscriptions, closed infrastructure dependency, and less self-hosting flexibility than open-source tools like MoneyPrinterTurbo.

License and Pricing

- **License**: MIT.

- **Official Pricing**: The software is open-source and free to use. However, third-party integrated services (such as paid LLMs, text-to-speech APIs, or video-generation endpoints) adhere to their own commercial pricing schemes, and verified universal pricing for all integrated services is unavailable.
