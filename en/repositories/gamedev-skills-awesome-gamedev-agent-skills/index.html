Purpose

`awesome-gamedev-agent-skills` provides a structured collection of portable capabilities packaged as `SKILL.md` files (following the Agent Skills open standard launched by Anthropic). It is designed to equip AI coding agents with deep domain knowledge across multiple game engines—including Godot, Unity, Unreal, Phaser, PixiJS, three.js, Bevy, pygame, LÖVE, Defold, and Roblox—using an intelligent router to load only the context required for a specific task.

Requirements

To use the automatic CLI installation workflow, the following is required:

- Node.js 22.20 or later.

For local development, testing, and validation of skill files, Python is utilized alongside the repository's validation scripts.

Installation

The recommended installation method uses the universal `skills` CLI via npx to automatically detect your coding agent and configure the files:

npx skills add gamedev-skills/awesome-gamedev-agent-skills

Alternatively, if you are utilizing Claude Code, you can install the marketplace plugin directly:

claude plugin marketplace add gamedev-skills/awesome-gamedev-agent-skills
claude plugin install gamedev@awesome-gamedev-agent-skills

Usage

After installation into your agent's respective skills directory (such as `.claude/skills/` or `.agents/skills/`), interact with your coding agent in plain language. The built-in master router evaluates project files to detect the target engine and selectively loads only the relevant engine basics, genres, and discipline playbooks.

Limitations

- Engine detection relies on standard project markers (e.g., `project.godot`); custom setups might require manual specification.

- Skill sets are pinned to specified software baselines (such as Godot 4.7 or Unreal 5.8), meaning significant engine version leaps might require manual code adjustments.

- Directory structures for skill storage vary slightly depending on the specific AI client used.
