FreeVideo is a local inference engine for MiniMax H3 on consumer GPUs that adapts hardware execution and memory usage to your available equipment. A concrete use case involves generating video clips via a ComfyUI interface on your own computer using a packaged environment for Windows, macOS, or Linux.

When to Use It

Use FreeVideo when you want to generate video content powered by the MiniMax H3 model directly on your own hardware with as little as 8 GB of VRAM and 16 GB of RAM, rather than relying on hosted cloud services.

What You Need

You need a computer running a supported operating system (Windows, macOS with Apple silicon, or Linux), available storage space, and a compatible graphics card (such as an NVIDIA GPU or Apple unified memory).

Where to Get It

You can obtain the official packages and launchers directly from the official GitHub repository at https://github.com/FlashML-org/FreeVideo.

Installation

For existing ComfyUI environments or terminal-based Linux installations, you can download the repository and initiate the setup using terminal commands.

First Use

Once the repository is cloned, you can execute the setup scripts or launch the server via the command-line interface to open the workspace in your local web browser.

Limitations

The model requires specific hardware resources and certain features on Mac are in a preview state. Hosted cloud access is separate from this local installation.

License and Pricing

The source code is released under the Apache 2.0 License. The model weights are licensed under the MiniMax H3 Community License. Verified pricing for paid commercial tiers is not documented in this open-source package.
