What Bland adds

Bland AI provides infrastructure for phone agents. Its official integration connects compatible clients to calling, messaging and conversation-management tools. The Instagram Reel was a discovery lead; the technical statements below come from Bland's own documentation and product pages. We have not placed calls or purchased a subscription.

Claude Code, MCP and REST

Bland documents a hosted MCP endpoint at https://api.bland.ai/v1/mcp. Claude Code can use the integration with an authorized organization. A connection alone does not complete a phone call: authentication, available tools and approval of external actions still matter. MCP OAuth tokens are not REST API credentials. Check Bland's separate authentication instructions when building a REST integration.

Installation and setup

The official CLI requires Node.js 18 or later. Its documented commands include the following; they are shown as instructions, not executed tests:

npm install -g bland-cli
bland auth login --device
bland mcp

Device login starts a browser approval flow. The last command runs the CLI's local MCP server. This is an alternative to the hosted server, rather than a requirement to install both. Review access before connecting and keep credentials out of source control.

The dedicated agent line

Agent Phone Plan provides a US local number for an agent, with calls and SMS to US and Canada destinations, fair-use constraints and one concurrent call. It should not be described as a plan for calling Spain. The account owner chooses and approves the subscription; this article does not start onboarding or approve a purchase.

Prices and conflicting limits

The commercial page advertises an introductory offer followed by a monthly fee. The agent-instructions page presents pricing differently and lists different call-frequency limits. Both official sources are linked. Check the account dashboard and applicable terms before subscribing; we do not turn conflicting documentation into a universal price or promise unrestricted calling.

Practical uses and limitations

Availability enquiries and request handling illustrate potential tasks, not guaranteed outcomes. Results depend on the conversation design and permissions. Compared with calling REST directly, MCP exposes tools inside the coding-agent client, while REST supports a custom integration. Neither removes costs, approval controls or responsibility. Bland states that compatibility is not a partnership or endorsement by Anthropic. Use the official documentation for implementation details; no unverified public repository or open-source license is attributed to the service.
