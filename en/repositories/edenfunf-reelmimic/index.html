Purpose and Functionality

ReelMimic is a software tool designed to ingest a reference video—via file upload, phone recording, or a YouTube link—and generate a completely original video matching its style and editing pacing. The system analyzes the reference's shot counts, durations, transitions, framing, colors, and camera movements.

It then formulates a detailed storyboard and production plan for the user to evaluate and modify via chat. Once approved, the system delegates production tasks across multiple concurrent AI agents. Every completed shot undergoes independent review by a separate agent, utilizing verification screenshots to ensure quality before final assembly.

Requirements and Setup

To run ReelMimic locally, the official source documentation mandates the following dependencies:

- Node.js 22.18 or higher.

- Python 3.10 or higher.

- FFmpeg.

- Google Chrome.

- Claude Code or Codex CLI (authenticated and logged in).

### Installation

Clone the repository and run the provided setup scripts:

git clone https://github.com/edenfunf/reelmimic.git && cd reelmimic
./install.sh
./start.sh

For Windows users, double-click `install.bat` and `start.bat`. Access the web interface at `http://localhost:4318`. You can re-run environment diagnostics anytime using `cd app && npm run doctor`.

Usage and Configuration

API keys and custom environment paths reside in `~/.reelmimic/secrets.json`, following the format found in `secrets.example.json`. Key parameters include `YATING_KEY`, `ELEVENLABS_API_KEY`, `PIXABAY_KEY`, `FREESOUND_KEY`, as well as executable paths like `FFMPEG_DIR`, `CHROME_PATH`, `CODEX_BIN`, and `PYTHON`.

For optional social media syndication of completed and reviewed projects, use the Upload-Post utility located inside the `app/` folder:

npm run post-video -- <project id> --platforms tiktok,instagram,youtube

Limitations

- Restricted to 2D animation only, supporting seven drawing engines (vector/motion graphics, hand-painted watercolor, crayon picture book, pixel art, paper cut-out stop-motion, whiteboard doodle, and anime cel).

- Rendering duration is substantial, taking between 1.3.5 hours for a 30 to 60-second video depending on visual complexity.

- Execution relies on your personal Claude Code or Codex usage tier limits.

- Officially tested primarily on Windows platforms.

Alternatives and Editorial Comparison

Traditional video generation tools typically operate as single-prompt cloud services that output final clips instantly without user-in-the-loop validation. In contrast, ReelMimic acts as a local agentic crew framework, providing transparent multi-agent reasoning, self-correction loops with visual proofs, and granular styling controls.

License and Official Pricing

The codebase is licensed under the **MIT License**. Verified pricing from official sources states that the software itself is open source and free to use, though operational costs depend entirely on the user's connected AI provider accounts (Claude Code or Codex) and optional external APIs.
