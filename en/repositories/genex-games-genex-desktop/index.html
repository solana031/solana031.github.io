Purpose

Genex Desktop is a desktop application designed for AI-assisted game development. It allows developers to use Claude Code or ChatGPT subscriptions, run local models, deploy multi-agent game development by mixing Opus and GPT models across agents and reviewers, create local 3D assets using a Blender plugin, and interface with external services like Meshy, Tripo, and ElevenLabs through its tools router.

Requirements

Contributing to the repository requires macOS on Apple Silicon, Git, and Node.js version 24 (managed via nvm using `.nvmrc`). For end users, official installers are provided for macOS (Apple Silicon), Linux (x64 via `.deb`, `.rpm`, or `.zip`), and Windows (x64 preview builds).

Installation and Setup

End users can download prebuilt binaries directly from the official release page. To set up the development environment locally from the source repository, execute the following commands:

git clone https://github.com/genex-games/genex-desktop.git
cd genex-desktop
nvm install && nvm use
npm ci
npm run studio:dev -- start --profile first-run --fixture app-basics

Usage

Genex enables multi-agent workflows, local asset generation, and integration with game engines such as Unreal and Godot. Developers can also scaffold and diagnose custom plugins using integrated CLI tools:

npm run plugin:new -- my-plugin --out ~/studio-plugins
npm run plugin:doctor -- ~/studio-plugins/my-plugin

Limitations

Genex is in an early development stage, meaning users should expect rough edges and occasional operational hurdles. Windows builds are currently distributed as unsigned previews, requiring manual user intervention to bypass operating system warnings upon execution.

Alternatives and Editorial Comparison

Unlike conventional game engines or standard integrated development environments that lack native agent orchestration, Genex embeds multi-agent intelligence directly into the studio workflow. Its modular plugin ecosystem provides an extensible bridge compared to closed toolchains.

License and Pricing

Genex is released under the MIT license. Verified official pricing details are unavailable in the source documentation; any associated costs depend on external model subscriptions (such as Claude Code or ChatGPT) utilized within the application.
