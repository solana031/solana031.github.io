Purpose and Overview

**REA (Reverse Engineer Anything)** is a Model Context Protocol (MCP) server and toolkit designed to bridge artificial intelligence agents with low-level software analysis. Its primary purpose is to allow an AI agent to investigate specific features in applications without access to their original source code, explain how they work down to the binary or intermediate code level, collect verifiable evidence, and help build equivalent implementations for new projects.

REA connects agents to specialized inspection tools for native binaries, JavaScript and Electron applications, `.NET` assemblies, websites, crash dumps, and firmware packages. All analysis runs locally on the user's machine, tying results directly to the collected evidence and technical limitations encountered.

System Requirements and Documented Setup

To use REA, specific technical prerequisites outlined in the official documentation must be met:

- **Node.js**: Versions 22.x (>=22.19), 24.x (>=24.11), or 26+.

- **Package Manager**: npm.

- **OS Prerequisites**: On Linux systems, static JavaScript/Electron analysis, Ghidra execution, JADX, and firmware tools require a `procps`-compatible `ps` utility on the `PATH` for process ownership checks.

- **Optional Native Analysis Engines**: Deep native binary analysis requires an existing installation of Hopper, Ghidra, or IDA Pro, or alternative static providers.

### Agent Setup and Configuration

Initial setup to register REA with your supported agent is performed using the following documented command:

npx rea-agents setup

This command lets you select your preferred agents (such as Claude Code, Cursor, Gemini CLI, among others), review the proposed changes, and add them along with matching workflow instructions.

To install the command-line interface (CLI) globally for regular use:

npm install --global rea-agents
rea --help

Usage and Practical Examples

Once configured, you can interact directly with your agent or use REA's CLI. For instance, to inspect an extracted JavaScript/Electron application directory or ASAR file, run:

npx -y rea-agents@latest analyze-javascript-application /absolute/path/to/app --json

To keep your global REA installation up to date with frequent bug fixes and enhancements, use:

rea update

Advantages

- **Agent-Driven Automation**: Enables AI assistants to analyze complex behaviors and search for patterns in compiled or packaged code.

- **Local Execution**: All reverse-engineering analysis executes locally within the user environment, preserving control over data.

- **Multiplatform and Multi-format Support**: Ranges from native ELF/PE/Mach-O binaries, EVM bytecode, WASM artifacts, and SQLite databases to Android APK packages and Flutter apps.

- **Evidence-Based Traceability**: Every conclusion generated by REA includes the corresponding technical evidence and identified analysis limitations.

Limitations

- **External Tool Dependencies**: Deep analysis of native binaries or mobile applications requires prior manual installation of specialized third-party software (such as Hopper, Ghidra, IDA Pro, or JADX).

- **Commercial License Restrictions**: REA does not include or grant licenses, keys, or activation entitlements for proprietary commercial tools. Users must legally obtain and be authorized to use such tools under their applicable terms.

- **Local Operational Restrictions**: Live runtime analysis requires appropriate user permissions and is subject to the security constraints of the host operating system.

Editorial Comparison and Alternatives

Unlike traditional static disassembly tools that operate in isolation (such as Ghidra or IDA Pro individually), REA acts as an abstraction layer and MCP bridge explicitly engineered to integrate AI agent workflows into the reverse-engineering pipeline. Other alternatives include manually driving decompilers or writing custom scripts using frameworks like `pwntools` or `rizin`, though they lack native integration with agent context protocols provided by REA.

License and Pricing

- **License**: Code authored and contributed directly to REA is licensed under the **MIT License**. Third-party materials retain their own original copyright notices and licenses.

- **Pricing**: The `rea-agents` npm package and GitHub source code are open source and free. However, supporting commercial analysis tools (such as IDA Pro or Hopper) require independent licenses from their respective vendors; verified pricing information is unavailable within the official REA package.
