Learn how to use Reverse API Engineer to transform any website into a typed API client using your terminal.

Purpose and use case

The purpose of Reverse API Engineer is to automate the creation of application programming interface (API) clients from captured website network traffic, simplifying data extraction and automation without manual developer tools analysis. A concrete use case is fetching all job openings from a corporate careers page to integrate them into an automated script.

When to use it

Use this tool when you need to programmatically interact with a website that lacks official public API documentation and you prefer to generate a typed client in languages such as Python, JavaScript, Go, or PowerShell based on real browser traffic.

What you need

You need a terminal with command-line access, Python 3.11 or higher, a valid API key for agent mode, and a supported operating system (Linux, Apple Silicon macOS, or 64-bit Windows). The underlying cryptography dependency requires 64-bit platforms and does not support legacy environments like 32-bit Windows or Intel macOS.

Where to get it

The official source code and package are hosted in the GitHub repository `kalil0321/reverse-api-engineer` and on the Python Package Index (PyPI) under `reverse-api-engineer`.

Installation

To perform a standard installation on your system, run the following command in your terminal:

uv tool install reverse-api-engineer   # or: pip install reverse-api-engineer

If you want to use manual mode which controls a local Playwright browser, you must install the optional extras by executing:

uv tool install "reverse-api-engineer[manual]"   # or: pip install "reverse-api-engineer[manual]"
playwright install chromium

First use

Launch the command-line interface by typing the primary command in your terminal:

reverse-api-engineer

Once the interface opens, enter a prompt indicating which site to visit and your goal, for example:

> fetch all apple jobs from their careers page

Limitations

Websites enforcing strict bot detection may block traffic capture or require continuous manual interaction. Additionally, generated code must be reviewed locally before execution in production environments to ensure safety and correctness.
