Purpose and Overview

HyperFrames is an open-source framework built to transform HTML, CSS, media, and seekable animations into deterministic MP4 videos. It is specifically engineered to run locally via the command-line interface, through AI coding agents equipped with specialized skills, or as the underlying rendering core behind hosted authoring workflows.

Unlike frameworks that mandate specific component architectures like React, HyperFrames relies on plain HTML enhanced with custom data attributes to handle timing, tracks, and seekable animations. This makes compositions easily readable and writable by both human creators and automated coding agents such as Claude Code, Cursor, Codex, and Gemini CLI.

System Requirements

To run HyperFrames locally and execute rendering workflows, the environment must fulfill the requirements documented by the official package:

- Node.js version 22 or higher

- FFmpeg

Installation and Setup

Projects can be initialized and executed manually through the CLI using the following official commands:

npx hyperframes init my-video
cd my-video
npx hyperframes preview
npx hyperframes render

For AI coding agents such as Claude Code, plugins can be added through dedicated marketplace commands:

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

Standalone agent skills can also be registered via the registry integration:

npx skills add heygen-com/hyperframes

Usage and Operation

Compositions are constructed using standard HTML structures enriched with data attributes for timeline management. The rendering pipeline utilizes a headless version of Chrome to capture individual frames accurately and encodes the video stream using FFmpeg.

Additional visual blocks and pre-made components can be added directly into projects using the CLI catalog helper:

npx hyperframes add flash-through-white
npx hyperframes add instagram-follow
npx hyperframes add data-chart

Advantages

- **HTML-Native:** Compositions are standard HTML files without mandatory framework dependencies or proprietary timeline formats.

- **Agent-Friendly:** Purpose-built for AI coding agents to write, lint, preview, and render videos seamlessly.

- **Deterministic Output:** Identical inputs generate identical frames, making it ideal for automated regression testing and CI pipelines.

- **No Build Step Required:** Standard composition files can be previewed directly within the browser with live reloading capabilities.

Limitations

- Relies on underlying system dependencies such as Node.js and a properly configured FFmpeg installation.

- Complex timeline adapters require careful validation to ensure frame-accurate synchronization across different animation libraries.

- Full source code checkouts require Git LFS for regression test baselines due to binary asset sizes.

Editorial Comparison with Alternatives

HyperFrames is often compared to solutions like Remotion. While Remotion focuses on React-based component authoring and requires a JavaScript bundler, HyperFrames emphasizes plain HTML, CSS, and explicit data attributes to simplify agent handoffs and manual edits without requiring component transpilation steps.

License and Official Pricing

HyperFrames is open-source software licensed under the **Apache 2.0** license. Verified commercial pricing information is unavailable in the source documentation, as the core rendering framework is provided openly without per-render platform fees or commercial license tiers.
