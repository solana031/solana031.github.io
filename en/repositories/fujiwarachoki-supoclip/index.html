SupoClip Guide: Open-Source OpusClip Alternative for AI Video Clipping

SupoClip is an open-source AI-powered video clipping tool licensed under AGPL-3.0 that extracts viral moments from long-form videos, podcasts, or streams, offering self-hosting capabilities and hosted cloud deployment options.

Purpose

SupoClip is designed as an open-source alternative to proprietary clipping platforms like OpusClip, enabling creators to process long-form videos from YouTube, Twitch, Kick, or local uploads into vertical 9:16 clips. The system leverages artificial intelligence to identify viral-worthy moments, score them, generate word-synced subtitles, apply face-centered smart cropping, and render hook titles without platform lock-in or forced watermarks.

Requirements and Setup

To run SupoClip using Docker, the documented prerequisites include:

- Docker and Docker Compose.

- An AssemblyAI API key for transcription services.

- An LLM provider API key (Google, OpenAI, Anthropic, or a local Ollama model).

The official commands to clone and initialize the repository are:

git clone https://github.com/FujiwaraChoki/supoclip.git
cd supoclip

Next, a `.env` file must be created in the root directory with the appropriate keys before launching the containers.

docker-compose up -d

Usage

Once the stack is running, users can access the local web interface at the designated port (defaulting to `http://localhost:3107`), create an account, and begin processing video content. Alternative usage channels documented by the source include an iOS app on the App Store, a REST API, an MCP server for clients like Claude or Cursor, and the hosted cloud web application.

Advantages

- Open-source distribution under the AGPL-3.0 license, ensuring code transparency and extensibility.

- Full self-hosting capabilities, allowing users to process workloads on their own hardware without strict cloud metering.

- Zero mandatory platform watermarks on exported clips.

- Broad flexibility in choosing LLM providers and transcription engines.

Limitations

- Live streams are explicitly not supported; imports are restricted to VODs, clips, or direct file uploads.

- Self-hosting requires external paid API keys (such as AssemblyAI and LLM providers) unless configured with fully local alternatives like Whisper and Ollama.

- Initial deployment demands familiarity with Docker and environment variable configuration.

Editorial Comparison and Alternatives

Compared to commercial services like OpusClip, SupoClip removes usage tier restrictions and branding constraints at the expense of requiring self-managed infrastructure or reliance on community-driven setups. While traditional tools lock content and workflows into proprietary servers, SupoClip emphasizes data ownership and architectural transparency.

License and Pricing

SupoClip is released under the AGPL-3.0 open-source license. Regarding official pricing, verified pricing tiers are unavailable in the source material, though the software itself is free to self-host.
