Purpose

Stickman Video Director turns a script, topic, or web link into an animated stickman video with voiceover, captions, and sound effects, without requiring a camera or filming equipment. A concrete use case is a faceless YouTube creator who needs a 90-second science explainer in 16:9 and uses Autopilot Mode to produce a complete video file from a rough topic.

What it is and how it works

Stickman Video Director is an open-source Skill, which means a set of instructions that you load into an AI assistant rather than a traditional program you install with a package manager. The official repository is kaomei/stickman-video-director on GitHub. The project offers two production modes. Director Mode, also called Mode A, is for creators who want control over every shot. The AI assistant plans the storyboard, writes scene-by-scene video prompts, and designs sound cues. You then copy those prompts into an external video generator such as Google Flow, Runway, Luma, or Kling, generate the clips, and assemble them in an editor like CapCut or Premiere. This mode is recommended for short videos, typically 30 seconds to 3 minutes. Autopilot Mode, also called Mode B, is for creators who want a finished video without assembling scenes themselves. You give the assistant a topic, article, link, or brief, and it plans scenes, generates visuals and narration, adds captions and sound effects, and renders a complete video file timed to the voiceover. This mode runs inside AI coding agents such as Codex, Claude Code, or Cursor, which are programs that can read and write files, run commands, and use tools on your behalf. Autopilot Mode is oriented toward long-form videos of 10 minutes or more, though it also works for shorts and episodic stories. Both modes support aspect ratios of 9:16, 16:9, and 1:1, and you can choose the narration language and voiceover freely. The project includes visual styles numbered A1 through A7 for Director Mode and B1 through B5 for Autopilot Mode, ranging from classic black-and-white line art to colorful hand-drawn scenes. Heavy visual generation is handled through cloud APIs or procedural rendering, not your local computer's graphics card, according to the documentation.

When to use it

Use this project when you run a faceless YouTube channel and need animated explainers without appearing on camera. Use it when you want to convert a blog post, news link, or rough idea into a narrated video with captions and sound effects. Use Director Mode when you need scene-by-scene prompts to generate clips in external video generators and then edit them yourself.

What you need

You need a computer with internet access and an AI assistant that can install and run the Skill. For Director Mode, any Skill-compatible conversational AI assistant is sufficient. For Autopilot Mode, you need an AI coding agent with file and terminal access, such as Codex, Claude Code, or Cursor; the documentation does not state that every assistant works equally well, and it notes that results can differ between models and configurations. You do not need programming skills or a high-end graphics card, according to the FAQ. If you want to connect image, voice, or video generation services, you may need accounts or API keys for third-party providers. The README mentions examples such as Google Gemini, Claude, ElevenLabs, Google Flow, Runway, Luma, and Kling, but using them is optional and the project itself does not require a specific provider. No supported operating system or runtime version is documented in the package.

Where to get it

The official download location is the GitHub repository at https://github.com/kaomei/stickman-video-director. The default branch is main. A release tagged v2026.11.11.2 exists, but no standalone installer file is documented in the release assets. This is hosted access: you obtain the Skill by pointing your AI assistant to the repository URL. There is no documented local installation method such as a git clone or npm install command.

Installation

No terminal command for installation is documented in the official README or release notes. Instead, the documented first step is to send the following text to your AI assistant: Install this Skill for me: https://github.com/kaomei/stickman-video-director. Once installed, you should ask the assistant to read the installed SKILL.md file immediately. The README recommends starting with Codex for results closest to the showcase examples, but this is a recommendation, not a requirement. Because no local installation command is documented, you cannot verify a local setup through a terminal command; you rely on the AI assistant to configure the Skill.

First use step by step

Open your AI assistant. If you are using Autopilot Mode, confirm that it has file and terminal access. Send the installation text to the assistant and ask it to read SKILL.md. Decide which mode to use. For Autopilot Mode, paste a topic, article, link, or brief and specify the length, aspect ratio, style, and that you want voiceover, captions, and sound effects. Ask the assistant to check the image generation, voiceover, and video-rendering setup first, then produce a script and a 20-second preview with sound. Approve the script and preview, then let the assistant build the full video and deliver the finished video file. For Director Mode, send your topic and request a director's treatment. After approving the treatment, ask for scene-by-scene video prompts. Copy each prompt into your chosen external video generator, generate the clips, and finish the edit in CapCut, Premiere, or your preferred editor. You can optionally request the Thumbnail & Publishing Kit after the final video is confirmed; this generates a matching cover image, title variants, description, tags, and an engagement question, but image generation depends on an available tool and any required cost approval.

Common errors and how to solve them

The documentation does not provide a list of terminal error codes, but it describes several predictable situations. Results can differ between AI assistants because of models, tool configuration, and execution; if your output does not match the showcase examples, the project recommends using Codex for the closest match. On first use of Autopilot Mode, the assistant checks required setup and walks you through anything missing; if a step fails, follow the assistant's guidance rather than guessing a command. If image generation is unavailable, the assistant should explain the gap and still deliver the text portions of the publishing kit. Character consistency can be difficult in Director Mode when using text-to-video generation for complex characters; the documentation suggests adding a stick-figure character reference image and reusing it across clips. No local GPU errors are expected because heavy generation is not performed on your hardware, according to the docs.

Limitations

This is not a standalone desktop or mobile application. Autopilot Mode requires an AI coding agent with file and terminal access, so it will not work in assistants that lack those capabilities. The project is free, but third-party API usage for images, voice, or video is your financial responsibility, and verified pricing for those services is not included in this package. Monetization eligibility and Content-ID clearance on YouTube or TikTok are not guaranteed, as stated in the Thumbnail & Publishing Kit section. The project's release notes say that 200 offline runtime tests and regression checks validate execution rules, not creative quality or live-provider output. Style A7 is listed as coming soon and is not available.

Alternatives and how it compares

Compared to manual video editors such as CapCut or Premiere, Stickman Video Director automates planning and rendering through an AI assistant, but Director Mode still requires you to generate clips externally and assemble them yourself. Compared to dedicated AI video platforms such as Runway, Luma, Kling, or Google Flow, this project adds stickman-specific storyboarding, style presets, and an autopilot workflow that those platforms do not provide as a packaged Skill. Compared to subscription-based faceless-video SaaS services, this project is MIT-licensed and free to use, though you may still pay for third-party APIs you connect. No specific prices for alternatives are claimed here.

FAQ

Q1: Is this really 100 percent free? Yes. The project is released under the MIT license and is free for personal and commercial use. You only pay for third-party API usage if you choose to connect services such as image, voice, or video generation.

Q2: Do I need programming skills? No. The documentation states that no coding knowledge or expensive GPU is required. Autopilot Mode is operated through conversational English inside an AI coding agent.

Q3: Can I monetize the videos on YouTube and TikTok? The project says yes because the output uses custom storytelling arcs and original visual staging, but it also notes that monetization eligibility and Content-ID clearance are not guaranteed.

Q4: Do I need an existing script? No. You can start with a rough idea, a link, a news item, or a full blog post, and the AI director will extract the core conflict and structure the story.

Editorial assessment: who it is for and who should skip it

This guide is for people opening their first terminal who already use or are willing to use an AI coding assistant, especially faceless YouTube creators, educators, and storytellers who want animated stickman videos without filming. You should skip it if you need a traditional installable application with a graphical interface, if you do not have access to an AI coding agent with file and terminal access for Autopilot Mode, or if you are unwilling to manage third-party API accounts and possible usage costs.
