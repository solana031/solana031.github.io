Overview and Core Purpose

`cth9191/animate` is a skill plugin for Claude Code designed to build short procedural animated videos entirely in code using an HTML5 `<canvas>`. As documented in the official repository, the engine executes deterministically frame by frame and renders output to MP4 files via a headless Playwright Chromium browser and ffmpeg. It targets explainers, educational content, and product shorts using seven built-in aesthetic styles or custom visual looks matched from user references.

Prerequisites and Installation

According to the repository documentation, the required environment setup includes:

- Claude Code

- Node.js 18+

- Playwright with Chromium

- ffmpeg installed on the system PATH

- Local system fonts with cross-platform fallbacks (Windows, macOS, Linux)

- Optional for voice-overs: Python with `faster-whisper` for local word timing and an optional ElevenLabs connector configured in Claude Settings.

To set up the browser dependencies and install the plugin:

npm i -g playwright && npx playwright install chromium

Then execute inside Claude Code:

/plugin marketplace add cth9191/animate
/plugin install animate@animate

Alternatively, users can manually copy the skill folder to `~/.claude/skills/animate/`.

Workflow and Command Usage

The animation process follows a multi-step check-in workflow: Intake (initial parameters), Story check (beat table review), Look check (style frame confirmation), Storyboard (keyframe panel approvals), and Build/Delivery (rendering, audio mixing, and automated compliance checks).

You can request animations directly in Claude Code:

/animate a 45-second history of the bicycle, cut paper
/animate how a hash map works, in the math style

Developers can also run individual CLI utility scripts located in the `tools/` directory:

SKILL=~/.claude/skills/animate
node $SKILL/tools/build.mjs pieces/my-piece
node $SKILL/tools/export.mjs pieces/my-piece --share --formats 9:16,1:1,16:9
node $SKILL/tools/review.mjs pieces/my-piece

Built-in Styles and Custom Aesthetics

The repository ships with seven built-in styles: `cut paper`, `crosshatch`, `riso`, `sketchbook`, `math` (manim-like graphs), `pixel`, and `isometric`. Users can establish custom styles by providing reference images or URLs, which are measured using `tools/measure/refs.mjs` and compared side-by-side using `tools/compare.mjs`. A WebGL motion-design style is listed in the documentation as an upcoming feature ("Coming").

Advantages, Technical Limitations, and Alternatives

Key advantages documented in the repository include early visual check-ins to avoid rendering unapproved scenes, non-cropped layout adaptations across 9:16, 1:1, 4:5, and 16:9 aspect ratios, beat-mapped custom audio, and automated script-to-voice timing.

Limitations include external dependency requirements (Node.js, ffmpeg, Playwright, optional Python components) and reliance on Claude Code integration for command execution. Compared to traditional timeline video editors or AI text-to-video generation models, `cth9191/animate` relies on deterministic code execution over an HTML5 canvas, enabling exact visual control and repeatable renders.
