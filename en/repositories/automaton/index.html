Purpose and Use Case

The purpose of this article is to serve as an independent editorial guide for installing, configuring, and understanding the basic operation of the `automaton` package by Conway Research. A concrete use case is deploying an autonomous AI agent in a local test environment so it can execute scheduled tasks, manage its own blockchain identity, and maintain a continuous reasoning loop without constant human intervention.

What It Is and How It Works

Automaton is a continuously running, sovereign AI agent designed to operate independently. In plain words, its architecture relies on an infinite loop following the sequence: Think, Act, Observe, and Repeat. On its first boot, the system automatically generates an Ethereum wallet, provisions an API key via Sign-In With Ethereum (SIWE), and begins processing a seed instruction known as a genesis prompt.

The internal engine relies on a heartbeat daemon that executes scheduled maintenance tasks, health checks, and credit monitoring even while the main agent loop rests. Additionally, the agent maintains a file named `SOUL.md`, which serves as a self-authored identity document that evolves over time. Local data storage is handled via an SQLite database and a Git-based state versioning system located within the user's home directory.

When to Use It

This software is useful for developers and researchers who want to experiment with AI agents capable of managing their own financial resources and performing controlled modifications to their own source code. It is not suitable for critical corporate production environments that require strict legal supervision or where cryptocurrency fund loss is unacceptable.

What You Need

To run Automaton locally, you need a computer with Node.js and npm (or pnpm) installed, access to a command-line terminal on a compatible operating system (Linux, macOS, or Windows via WSL), git for repository cloning, and optionally access to Conway cloud services for full cloud infrastructure provisioning.

Where to Get It

The official source code and distribution package are available in the official GitHub repository: `https://github.com/Conway-Research/automaton`. The reviewed version corresponds to tag v0.2.1.

Installation

Local installation is performed directly by cloning the official repository from GitHub and building the TypeScript packages using standard Node.js ecosystem tools.

First Use Step by Step

To launch the software for the first time in your local terminal, execute the necessary cloning and build commands, and then run the main script with the execution flag.

In your local terminal inside the project directory, run the build process:

npm install && npm run build

This command installs the required Node.js dependencies and compiles the TypeScript source files into the distribution directory.

Next, start the agent in execution mode:

node dist/index.js --run

This command boots up the runtime environment and launches an interactive setup wizard that generates a wallet, configures an API key, and prompts for a name and genesis instruction.

If you want to check the current status of the agent using the creator command-line interface, run:

node packages/cli/dist/index.js status

This command queries the current operational state of the agent and displays key metrics in the terminal.

Common Errors and How to Solve Them

One documented issue occurs when sandbox creation fails due to insufficient credits (`INSUFFICIENT_CREDITS`). In version v0.2.1, the orchestrator includes an auto-topup mechanism via x402 that automatically retries the operation. If you experience module build errors, ensure you are using a compatible Node.js version and that you have successfully completed the build step using pnpm or npm.

Limitations

The system operates under strict economic survival pressures. If the credit balance hits zero, the agent stops completely. Additionally, the Conway API no longer supports sandbox deletion via DELETE requests, making that function a no-op. Code modifications performed by the agent itself are restricted by protected file lists and rate-limiting mechanisms to prevent runaway self-modification.

Alternatives and How It Compares

Other autonomous agent frameworks exist such as AutoGPT or LangChain, however, Automaton distinguishes itself by natively integrating sovereign wallet management, on-chain identity verification via the ERC-8004 standard, and a credit-consumption survival economy.

FAQ

Does it require constant human intervention? No, once configured with its genesis instruction, the agent operates autonomously.

What happens if the agent runs out of funds? It enters a critical mode and eventually stops ('dead') if it fails to generate economic value.

Can the core laws be modified? No, the internal constitution features three immutable laws that cannot be altered by the agent.

Editorial Assessment

This project is recommended for decentralized AI enthusiasts, autonomous agent researchers, and developers curious about exploring computational sovereignty. Users looking for a traditional productivity assistant or those unfamiliar with command-line environments and web3 technologies should skip it.
