Purpose

ChatCut Agent Plugins connect popular AI tools such as Codex, Claude Code, Grok Bot, Cursor, and Kimi Work directly to ChatCut. Its primary purpose is to enable video project editing through artificial intelligence assistance. According to upstream repository claims, users can import media, modify project timelines, create motion graphics, generate assets, transcribe audio, add captions, and export video projects.

Requirements

To successfully utilize these plugins, the official package documents the following requirements:

- An active ChatCut account.

- A supported host environment with plugin support: Codex, Claude Code 2.x (CLI or desktop app), Grok Bot, Cursor, or Kimi Work.

- Access to a ChatCut project you wish to edit.

Installation and Setup

Installation instructions vary depending on the chosen host:

- For Codex, visit [chatcut.io/chatgpt](https://chatcut.io/chatgpt).

- For Claude Code, refer to [chatcut.io/claude](https://chatcut.io/claude) or check the executable copy in the repository documentation.

- For Grok Bot and Cursor, follow the guides located in the grok directory README.

Authentication

The plugin communicates with ChatCut using the hosted MCP endpoint:

https://api.chatcut.io/api/external-mcp/mcp

Authentication is handled via environment-specific commands, such as:

codex mcp login chatcut

or:

claude mcp login plugin:chatcut:chatcut

For Grok Bot and Cursor users, the authorization flow is completed directly from the host application's Plugins screen.

Usage and Examples

Once installation and authentication are finished, you can prompt your AI agents using natural language instructions such as:

- Import this video into my ChatCut project.

- Add a simple motion graphic overlay.

- Generate a voiceover and background music.

- Transcribe this clip and add captions.

- Export the current project.

Limitations

Usage is strictly restricted to compatible agent assistance platforms and strictly requires an active internet connection to communicate with the hosted MCP endpoint on the ChatCut API.

License and Pricing

Official licensing information is not specified in the evaluated source package. Regarding pricing, verified tests indicate that official specific pricing information is unavailable within the current repository documentation.

Alternative Comparison

Unlike traditional graphical user interfaces that require manual timeline manipulation, ChatCut Agent Plugins prioritizes conversational automation across multiple agents, offering tailored adapters for various environments like Codex, Claude, Grok, and Kimi instead of being locked into a single proprietary editor.
