Purpose

VoiceStudio is an open-source application designed to run speech workflows entirely locally on your own hardware. Its core purpose is to provide a private, self-hosted alternative to commercial voice synthesis tools, enabling users to perform voice cloning, custom voice design, video dubbing with timed speech, transcription, dictation via a floating widget, and audiobook creation across 646 languages. The system is optimized to operate using local engines such as OmniVoice or CosyVoice, eliminating mandatory reliance on remote cloud services and ensuring absolute control over your audio assets and data.

System Requirements and Prerequisites

Hardware requirements vary depending on the chosen speech engine:

- **NVIDIA GPU (Windows / Linux):** Supports CUDA acceleration.

- **Apple Silicon:** Supports Metal (MPS) acceleration.

- **AMD GPU:** Optional native CosyVoice GGUF support using Vulkan when the community runtime is built with it.

- **No Dedicated GPU:** Fully usable on standard CPUs at a slower processing speed, automatically setting up the lightweight CPU build of PyTorch requiring about 5 GB of free disk space.

- **Windows on ARM:** Experimental support pending full validation.

- **Intel Mac:** Restricted to running the desktop UI connected to a remote backend.

For source builds and development environments, prerequisites include Git, Node.js 22+, Bun, Rust/Cargo, and platform build tools.

Installation

For macOS and Linux, the documented one-command installation is executed via terminal:

curl -fsSL https://voicestudio.sh/install | sh

To install a specific published release of the Electron desktop app, append the version parameter:

curl -fsSL https://voicestudio.sh/install | sh -s -- --version X.Y.Z

On Windows systems, run the following command within PowerShell:

irm https://voicestudio.sh/install | iex

If the primary setup domain is unreachable, you can invoke the installation script directly from the raw repository source:

curl -fsSL https://raw.githubusercontent.com/debpalash/VoiceStudio/main/scripts/install.sh | sh

Usage

Open the VoiceStudio Electron desktop application, navigate to **Voice cloning**, choose a default voice or upload a clean reference audio recording, input your text, and generate speech. The application will prompt you to download the required local models upon initial execution of a new feature. Dedicated workspaces are also available for video dubbing, voice design, and model management.

Advantages

- Operates fully offline and locally, ensuring complete privacy of audio workflows.

- Broad language support spanning 646 languages.

- Combines multiple capabilities—cloning, dubbing, dictation, transcription, and audiobooks—into a unified desktop suite.

- Hardware acceleration support for NVIDIA CUDA and Apple Metal.

Limitations

- Running speech models purely on a CPU or integrated graphics without a dedicated GPU results in slower generation times.

- Certain platform architectures like Windows on ARM and older Intel Macs involve functional limitations or require remote backends.

- Local model weights require several gigabytes of free local disk space.

Alternatives and Editorial Comparison

Compared to commercial cloud-based alternatives like ElevenLabs, VoiceStudio provides a free, open-source, and locally runnable environment that avoids recurring usage fees and safeguards user data privacy. Unlike command-line-only audio libraries, VoiceStudio delivers a polished Electron desktop application and mobile companion apps.
