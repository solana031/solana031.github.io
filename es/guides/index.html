Guías prácticas

Empieza por un problema concreto y consulta las fuentes oficiales antes de instalar una herramienta. Estas doce guías ofrecen un primer recorrido.

666ghj-mirofish

Guía de instalación de MiroFish para principiantes

Aprenda a desplegar MiroFish, un motor de inteligencia de enjambre de código abierto, para simular escenarios y predecir tendencias en un entorno digital.

affaan-m-ecc

ECC: El Sistema de Optimización de Rendimiento para Harness de Agentes

ECC es un sistema operativo de ingeniería para harnesses de agentes como Claude Code, Codex y Kimi Code. Optimiza la ventana de contexto permitiendo planificar, probar y verificar código antes de construirlo, mediante un enfoque open-source basado en habilidades, agentes especializados y herramientas de seguridad.

anomalyco-opencode

OpenCode: El Agente de Código Open Source

Guía completa de OpenCode, un agente de codificación de código abierto disponible para interfaz de terminal y aplicación de escritorio con soporte multiagente.

automaton

Guía completa de Automaton: el agente autónomo soberano

Aprende a desplegar y configurar Automaton, un agente de IA autosuficiente que gestiona sus propios recursos, se replica y evoluciona en un entorno Linux.

bangtutorial-bang-motion

Bang Motion: Convierte tu Agente de IA en Diseñador de Movimiento

Guía oficial y habilidad de agente para Bang Motion (bangtutorial/bang-motion), una herramienta que transforma prompts en gráficos en movimiento de calidad profesional en un solo archivo index.html.

bland-ai-claude-code-agent-phone-plan

Bland AI y Claude Code: MCP, API y un número para tu agente

Qué confirma Bland sobre Claude Code y su Agent Phone Plan, cómo empezar y qué límites conviene revisar.

blixvip-html-anime

Guía de html-anime: Creación de Animación con IA mediante Código HTML

Explora html-anime, una herramienta que transforma prompts de escenas en hojas de planos para que agentes de codificación dibujen animaciones puramente en HTML, sin utilizar modelos de video tradicionales.

calesthio-openmontage

OpenMontage: Sistema de Producción de Video Agentico de Código Abierto

Guía completa de OpenMontage, un sistema de producción de video controlado por agentes de IA integrado con tu asistente de código para crear videos completos desde cero o utilizando material de archivo gratuito.

chatcut-inc-agent-plugin

Guía Editorial de ChatCut Agent Plugins: Edición de Video Asistida por IA

Aprende a integrar ChatCut con Codex, Claude Code, Cursor y otros agentes locales para editar videos, generar subtítulos y recortar silencios mediante comandos de lenguaje natural.

clone-any-viral-video-with-ai-agents-open-source

Hypit: Guía Completa de Clonación de Videos Virales con Agentes de IA

Exploración detallada de Hypit, una herramienta de código abierto para clonar videos virales, editar secuencias completas mediante agentes de IA y generar variantes a escala utilizando modelos BYOK.

cth9191-animate

Creación de Animaciones Procedurales con Código en Claude Code

Guía completa para utilizar Animate, una herramienta de Claude Code para crear videos animados cortos directamente desde el código utilizando Node.js y un navegador sin interfaz gráfica.

debpalash-voicestudio

VoiceStudio: Guía completa para principiantes - clonación de voz local en 646 idiomas

Guía independiente sobre VoiceStudio, alternativa local a ElevenLabs. Aprende a instalar, clonar voces, dublar videos y transcribir audio sin nube ni cuenta.
