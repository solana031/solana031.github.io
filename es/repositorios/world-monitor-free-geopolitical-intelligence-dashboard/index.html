Propósito y Visión General

World Monitor se presenta en su documentación oficial como un panel de inteligencia geopolítica en tiempo real diseñado para analistas, periodistas, comerciantes y desarrolladores que necesitan señales geopolíticas en directo. El proveedor describe que el servicio gratuito recopila y transmite 469 noticias y fuentes OSINT de 770 proveedores atribuidos en un único mapa mundial interactivo que incluye 58 tipos de capas de mapas, abarcando áreas como geopolítica, mercados, envíos, aviación y ciberseguridad.

Requisitos y Configuración Documentada

Según las fuentes del proveedor, el panel está optimizado para la web y se puede consultar directamente sin requerir registros obligatorios. La documentación también detalla un servidor API y MCP (Model Context Protocol), con integraciones previstas a través de npm, PyPI, Go y RubyGems para desarrolladores.

Uso y Capacidades

La documentación oficial describe rutas de evidencia estructuradas para distintas tareas analíticas:

1. **Verificar un evento de última hora**: Consultar rastreadores de crisis y métricas fechadas.

2. **Inspeccionar un punto de estrangulamiento (chokepoint)**: Revisar el estado de interrupciones y flujos de embarcaciones en 13 pasos marítimos.

3. **Explicar un movimiento de riesgo país**: Rastrear señales políticas, de seguridad y económicas en 170 países.

Afirmaciones del Proveedor frente a Lectura de Fuentes

* **Afirmaciones del Proveedor**: El creador declara que el servicio cuenta con más de 2 millones de usuarios y opera bajo la licencia AGPL-3.0 con complementos profesionales.

* **Lectura de Fuentes**: La revisión de la documentación y metadatos públicos confirma la existencia de descripciones sobre las 58 capas de mapas, las fuentes de noticias OSINT y las opciones de integración mediante API y MCP.

Ventajas y Limitaciones

* **Ventajas**: Acceso web descrito como gratuito sin registro previo, múltiples capas cartográficas y soporte documentado para desarrolladores y agentes de IA.

* **Limitaciones**: Funciones avanzadas como el índice de divergencia de primas físicas o los rankings de vulnerabilidad de suministro figuran como características PRO.

Alternativas y Comparativa Editorial

A diferencia de plataformas privativas y comerciales cerradas, las fuentes del proyecto destacan su naturaleza de código abierto bajo la licencia AGPL-3.0 y una capa base gratuita para la visualización de datos geopolíticos.

Licencia y Precios Oficiales

El servicio base se describe como gratuito ($0) y de código abierto bajo la licencia AGPL-3.0. Las características comerciales adicionales (PRO) se rigen por los términos oficiales del proveedor.
