Propósito

MoneyPrinterTurbo es una herramienta de código abierto y de una sola parada diseñada para generar videos cortos en alta definición de forma automática. A partir de un tema o palabra clave, el software redacta guiones de video, empareja recursos audiovisuales, genera subtítulos y pistas de música de fondo, y finalmente sintetiza una pieza de video lista para plataformas como TikTok, Instagram y YouTube Shorts. Es compatible con múltiples interfaces que incluyen Agentes de IA, WebUI, API y una interfaz de línea de comandos (CLI).

Requisitos del Sistema

- **Sistema operativo**: Windows 10, macOS 11.0 o superior, y distribuciones principales de Linux.

- **Python**: Se requiere Python 3.11 o superior (se recomienda encarecidamente Python 3.11).

- **Hardware**: La GPU no es estrictamente obligatoria si se utilizan proveedores en la nube. Sin embargo, se recomienda una tarjeta gráfica dedicada con VRAM para transcripciones locales (`faster-whisper`), procesamiento de video más rápido y tareas por lotes.

| Elemento | Mínimo | Recomendado | Ideal |

| --- | --- | --- | --- |

| CPU | 4 núcleos | 6 a 8 núcleos | 8 núcleos o más |

| RAM | 4 GB | 8 GB | 16 GB o más |

| GPU | No obligatoria | 4 GB VRAM o superior | 8 GB VRAM o superior |

Instalación y Configuración

A continuación se detallan los métodos de instalación documentados oficialmente por el desarrollador.

### Clonar el Repositorio

git clone https://github.com/harry0703/MoneyPrinterTurbo.git

### Despliegue con Docker

Si utiliza Docker Desktop, asegúrese de cumplir con los requisitos previos para contenedores y ejecute:

cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up

### Instalación Manual con uv

Se recomienda utilizar `uv` para gestionar el entorno y las dependencias de Python:

uv python install 3.11
uv sync --frozen

Uso

Para iniciar la interfaz web (WebUI), ejecute los siguientes comandos según su sistema operativo:

En Windows:

.\webui.bat

En macOS o Linux:

sh webui.sh

Para ejecutar una generación puramente desde la línea de comandos sin abrir el navegador:

uv run python cli.py --video-subject "人工智能如何改变日常生活"

Ventajas

- Automatización integral desde el concepto inicial y redacción del guión hasta la exportación del video final.

- Soporte para una amplia gama de proveedores de modelos de lenguaje e interfaces de voz (como Edge TTS de forma gratuita, Azure, OpenAI, Claude, Gemini, DeepSeek, entre otros).

- Múltiples formatos de salida y relaciones de aspecto (`9:16`, `16:9`, `1:1`).

- Integración de código abierto con una comunidad activa y múltiples opciones de despliegue (Docker, WebUI, CLI, API).

Limitaciones

- La dependencia de servicios externos para modelos de IA o generación de voz requiere llaves de API (API Keys) válidas y posibles costes de uso según el proveedor.

- El uso intensivo local de modelos de transcripción como Whisper requiere recursos considerables de CPU y memoria, o una GPU dedicada para mantener un buen rendimiento.

- Las rutas en sistemas Windows no deben contener caracteres especiales, espacios ni caracteres en chino para evitar fallos de ejecución.

Alternativas y Comparativa Editorial

- **Editores de video tradicionales (ej. CapCut, Premiere)**: Ofrecen control manual exhaustivo de cada fotograma, pero carecen de la automatización impulsada por IA para la redacción de guiones y búsqueda automática de recursos multimedia.

- **Herramientas de conversión de texto a video SaaS en la nube (ej. InVideo, Pictory)**: Son más sencillas para usuarios sin conocimientos técnicos, pero suelen ser de pago estricto, dependen totalmente de infraestructuras cerradas y ofrecen menor flexibilidad de personalización en comparación con soluciones de código abierto como MoneyPrinterTurbo.
