Propósito y caso de uso

El propósito de esta guía es ayudarle a configurar por primera vez el motor de simulación MiroFish en su propia terminal para predecir futuros alternativos o probar escenarios sociales. Un caso de uso concreto es analizar noticias o informes para generar un entorno digital en el que miles de agentes inteligentes interactúan, permitiéndole observar posibles resultados de políticas o dinámicas de opinión pública.

Cuándo utilizarlo

Utilice esta herramienta cuando necesite procesar material de origen, como borradores de políticas o informes analíticos, y desee ejecutar simulaciones de múltiples agentes para estudiar interacciones sociales emergentes o deducir trayectorias futuras.

Lo que necesita

Para completar esta instalación local, necesitará Node.js versión 18 o superior, Python en versión mayor o igual a 3.11 y menor o igual a 3.12, la herramienta de gestión de paquetes uv, una clave de API de un modelo de lenguaje compatible con el SDK de OpenAI y una clave de API de Zep Cloud.

Dónde obtenerlo

El repositorio oficial del proyecto se encuentra en GitHub bajo la dirección https://github.com/666ghj/MiroFish.

Instalación

Abra su terminal en su computadora y siga estos pasos de configuración local:

cp .env.example .env

Este comando copia el archivo de configuración de ejemplo para que pueda editarlo y agregar sus claves de API en la terminal de su sistema.

npm run setup:all

Este comando instala de manera automática todas las dependencias necesarias tanto para la raíz como para el frontend y el backend en la terminal.

Primer uso

Una vez instaladas las dependencias, inicie los servicios ejecutando el siguiente comando desde la raíz del proyecto en su terminal:

npm run dev

Este comando arranca simultáneamente el servidor frontend en http://localhost:3000 y el backend de la API en http://localhost:5001.

Limitaciones y licencias

Las simulaciones extensas pueden consumir una cantidad considerable de recursos del modelo de lenguaje, por lo que se recomienda realizar pruebas con pocas rondas al principio. El proyecto se distribuye bajo la licencia AGPL-3.0. No hay precios verificados disponibles en la documentación oficial, ya que el software es de código abierto y depende de los costos externos de sus proveedores de API.
