Guía de SupoClip: Alternativa de Código Abierto a OpusClip para Recorte de Video con IA

SupoClip es una herramienta de recorte de video impulsada por IA de código abierto bajo licencia AGPL-3.0 que permite extraer momentos virales de videos largos, podcasts o transmisiones, con capacidades de autoalojamiento y opciones de despliegue en la nube.

Propósito

SupoClip surge como una alternativa de código abierto a plataformas comerciales como OpusClip, permitiendo a los creadores procesar videos largos de YouTube, Twitch, Kick o archivos locales para transformarlos en clips verticales de formato 9:16. El sistema utiliza inteligencia artificial para seleccionar los segmentos más relevantes, puntuarlos por su potencial de viralidad, aplicar subtítulos sincronizados por palabra, recortes centrados en rostros y títulos llamativos sin la imposición de marcas de agua o ataduras a plataformas de terceros.

Requisitos y Configuración

Para realizar una instalación basada en Docker, los requisitos documentados incluyen:

- Docker y Docker Compose.

- Una clave de API de AssemblyAI para la transcripción.

- Una clave de proveedor de LLM (Google, OpenAI, Anthropic o un modelo local mediante Ollama).

Los comandos oficiales para clonar e iniciar el repositorio son los siguientes:

git clone https://github.com/FujiwaraChoki/supoclip.git
cd supoclip

Posteriormente, se debe configurar un archivo `.env` en la raíz del proyecto con las variables requeridas antes de ejecutar el contenedor.

docker-compose up -d

Uso

Una vez que el sistema se encuentra en ejecución, se puede acceder a la interfaz web localmente en el puerto configurado (por defecto en `http://localhost:3107`) para crear una cuenta e iniciar el proceso de conversión de videos. Asimismo, el proyecto ofrece una aplicación para iOS en la App Store, una API REST, un servidor MCP compatible con clientes como Claude o Cursor, y una opción alojada en la web oficial.

Ventajas

- Código abierto bajo licencia AGPL-3.0, lo que otorga total transparencia y capacidad de auditoría.

- Capacidad completa de autoalojamiento para mantener el control total sobre los datos y la infraestructura.

- Ausencia de marcas de agua forzadas en los videos exportados.

- Integración con múltiples proveedores de LLM y motores de transcripción.

Limitaciones

- Las transmisiones de video en vivo (live streams) no son compatibles directamente; se requiere utilizar VODs o archivos subidos.

- Requiere claves de API de servicios externos de pago (como AssemblyAI o proveedores de LLM) a menos que se utilicen modelos locales configurados manualmente.

- La configuración inicial requiere conocimientos técnicos de Docker y gestión de variables de entorno.

Comparativa Editorial y Alternativas

Frente a soluciones propietarias como OpusClip, SupoClip elimina las restricciones de planes de pago por uso y la inserción de marcas de agua a cambio de asumir la gestión de la infraestructura en caso de optar por el autoalojamiento. Otras alternativas en el ecosistema comercial incluyen herramientas cerradas basadas en la nube, mientras que SupoClip prioriza la soberanía de los datos mediante su licencia AGPL-3.0.
