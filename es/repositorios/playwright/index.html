Qué es

Playwright es el proyecto de Microsoft para automatizar navegadores y probar aplicaciones web. Su documentación distingue el runner Playwright Test de la librería de automatización. Esta guía utiliza el runner: organiza pruebas, aserciones y resultados.

Para qué sirve

Un caso útil es comprobar que un usuario llega a una página y puede realizar su acción principal. Tener capturas bonitas no basta: conviene verificar un resultado visible, como un título o un estado guardado.

Actividad y fuentes

La selección procede del repositorio y de la documentación oficial. No afirmamos que esté creciendo por un número acumulado de estrellas. La metadata de GitHub puede consultarse por separado, con fecha; todavía no hay una serie histórica de crecimiento.

Instalación

La guía oficial parte de Node.js y de un gestor de paquetes compatible. Comprueba los requisitos vigentes en la documentación enlazada. El asistente prepara un proyecto de pruebas.

npm init playwright@latest
npx playwright test

Primer ejemplo

Este ejemplo sigue el patrón documentado; no demuestra conectividad con tu propia aplicación.

import { test, expect } from '@playwright/test';
test('home', async ({ page }) => {
  await page.goto('https://playwright.dev/');
  await expect(page).toHaveTitle(/Playwright/);
});

Cómo evaluar el resultado

Ejecuta la prueba, examina fallos y revisa el reporte. Si interceptas una API con respuestas simuladas, documenta esa limitación: no has verificado el servicio real. Para móvil, comprueba el viewport efectivo y no solo el tamaño de la ventana.

Ventajas y limitaciones

Locators, esperas automáticas y aislamiento facilitan pruebas repetibles. Aun así, selectores frágiles, autenticación y servicios externos necesitan diseño cuidadoso. No automatices pagos ni aceptaciones legales como parte de una prueba rutinaria.

Alternativas

Selenium y Cypress son opciones que puedes comparar con los requisitos de tu equipo. La decisión depende de navegadores, lenguaje, infraestructura y mantenimiento. Playwright se distribuye con Apache-2.0; consulta la licencia oficial antes de redistribuirlo.

Compatibilidad revisada

La documentación actual indica Node.js 22.x, 24.x o 26.x; Windows 11 o Windows Server 2019, macOS 14 o posterior, y versiones concretas de Debian y Ubuntu. Consulta la matriz oficial para tu sistema: no basta con que npm complete la instalación.
