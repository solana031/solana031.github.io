Propósito

Genex Desktop es una aplicación de escritorio orientada al desarrollo de videojuegos con Inteligencia Artificial. Permite utilizar suscripciones de Claude Code o ChatGPT, ejecutar modelos locales, emplear agentes múltiples de desarrollo mezclando modelos Opus y GPT, y crear activos tridimensionales locales utilizando un plugin de Blender, además de conectar con herramientas de enrutamiento como Meshy, Tripo y ElevenLabs.

Requisitos

Para contribuir al desarrollo del repositorio, se requiere una máquina con macOS en Apple Silicon, tener instalado Git y Node.js versión 24 (gestionado a través de nvm mediante el archivo `.nvmrc`). Para los usuarios finales, se distribuyen instaladores para macOS (Apple Silicon), Linux (x64 a través de paquetes `.deb`, `.rpm` o `.zip`) y Windows (x64 como versión preliminar).

Instalación y Configuración

La instalación para usuarios finales se realiza descargando los ejecutables desde la sección de releases oficiales. Para compilar y ejecutar desde el código fuente con fines de contribución, utilice los siguientes comandos:

git clone https://github.com/genex-games/genex-desktop.git
cd genex-desktop
nvm install && nvm use
npm ci
npm run studio:dev -- start --profile first-run --fixture app-basics

Uso

La aplicación permite gestionar agentes de desarrollo, crear activos en 3D, interactuar con tiendas de elementos dentro de la propia plataforma y construir proyectos para motores de juegos como Unreal o Godot. Para la creación y comprobación de plugins personalizados de agentes, se pueden emplear comandos específicos orientados al desarrollo de extensiones.

npm run plugin:new -- my-plugin --out ~/studio-plugins
npm run plugin:doctor -- ~/studio-plugins/my-plugin

Limitaciones

Genex es un software en una etapa temprana, por lo que se pueden encontrar detalles por pulir e imperfecciones operativas. Las compilaciones para Windows se ofrecen actualmente como una versión preliminar sin firma digital oficial de código, requiriendo que el usuario omita las advertencias del sistema operativo de manera manual durante la ejecución.

Alternativas y Comparativa Editorial

A diferencia de los entornos de desarrollo tradicionales (como IDEs puros o motores de juego aislados sin asistencia avanzada), Genex integra flujos agénticos múltiples de IA de forma nativa. Mientras que soluciones privativas centralizan la generación de activos, Genex apuesta por una arquitectura abierta basada en plugins y soporte multidispositivos.

Licencia y Precios

El proyecto se distribuye bajo la licencia MIT. Los datos sobre precios oficiales de servicios de terceros no se encuentran especificados explícitamente en la documentación verificada, por lo que las tarifas de modelos o pasarelas externas dependen enteramente de las suscripciones independientes del usuario (como ChatGPT o Claude Code).
