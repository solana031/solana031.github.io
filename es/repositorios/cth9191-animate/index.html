Visión General y Propósito Principal

`cth9191/animate` es una habilidad (skill) para Claude Code diseñada para generar animaciones cortas y de carácter procedimental ejecutadas completamente mediante código en un elemento `<canvas>`. Según la documentación del repositorio oficial, el sistema funciona de manera determinista fotograma a fotograma y renderiza el resultado final a formato de video MP4 utilizando un navegador headless (Playwright) y ffmpeg. La herramienta permite crear explicativos, narraciones o piezas cortas mediante 7 estilos integrados o mediante la coincidencia con referencias visuales personalizadas del usuario.

Requisitos Previos e Instalación

De acuerdo con las especificaciones del paquete, se requieren los siguientes elementos en el entorno de desarrollo:

- Claude Code

- Node.js versión 18 o superior

- Playwright con Chromium

- ffmpeg accesible en la variable PATH del sistema

- Fuentes del sistema local (con fuentes secundarias para Windows, macOS y Linux)

- Para locuciones: Python con la biblioteca `faster-whisper` para la sincronización de palabras y, opcionalmente, la conexión con ElevenLabs en Claude (Settings -> Connectors).

La instalación de dependencias y del plugin se realiza mediante los siguientes comandos:

npm i -g playwright && npx playwright install chromium

Posteriormente, dentro de Claude Code:

/plugin marketplace add cth9191/animate
/plugin install animate@animate

También es posible copiar manualmente el directorio del skill a `~/.claude/skills/animate/`.

Flujo de Trabajo y Uso de Comandos

El flujo operativo consta de 5 fases estructuradas: Intake (preguntas iniciales), Story check (tabla de ritmo y hechos), Look check (marcos de estilo a tamaño completo), Storyboard (paneles de fotogramas clave) y Build/Delivery (renderizado y entrega con verificación de normas de calidad).

Se pueden invocar animaciones desde la interfaz de comandos de Claude Code:

/animate a 45-second history of the bicycle, cut paper
/animate how a hash map works, in the math style

Asimismo, los usuarios pueden ejecutar directamente los scripts Node.js incluidos en el directorio `tools/`:

SKILL=~/.claude/skills/animate
node $SKILL/tools/build.mjs pieces/my-piece
node $SKILL/tools/export.mjs pieces/my-piece --share --formats 9:16,1:1,16:9
node $SKILL/tools/review.mjs pieces/my-piece

Estilos Integrados y Diseños Personalizados

El repositorio incluye 7 estilos integrados en carpetas dedicadas: `cut paper`, `crosshatch`, `riso`, `sketchbook`, `math`, `pixel` e `isometric`. Además, permite definir estilos propios proporcionando imágenes de referencia a la herramienta `tools/compare.mjs` y midiendo paletas y pesos de línea. La documentación señala que la integración con WebGL para animación en 3D se encuentra marcada como una función futura ("Coming").

Ventajas, Limitaciones Técnicas y Alternativas

Entre las ventajas documentadas destacan las comprobaciones paso a paso antes de gastar recursos de renderizado, la capacidad de exportar a múltiples formatos (9:16, 1:1, 4:5, 16:9) adaptando el diseño en lugar de recortar la imagen, y la sincronización con audio o capturas de productos reales.

Como limitaciones técnicas, el paquete depende de herramientas del sistema como ffmpeg, Playwright y opcionalmente modelos Python locales. En comparación con suites tradicionales de animación por fotogramas clave o generadores directos de video por IA basados en difusión, `cth9191/animate` ofrece un enfoque procedimental basado en código HTML5 canvas, proporcionando control determinista sobre cada elemento gráfico.
