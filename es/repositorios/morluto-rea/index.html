REA: Ingeniería Inversa Asistida por Agentes

Guía completa de REA (morluto/rea), un servidor MCP y herramienta de línea de comandos para realizar ingeniería inversa en binarios nativos, aplicaciones JavaScript/Electron y código gestionado mediante agentes de IA.

Propósito

REA (Reverse Engineer Anything) es un servidor Model Context Protocol (MCP) y una herramienta de línea de comandos diseñada para conectar agentes de inteligencia artificial con flujos de trabajo de ingeniería inversa. Permite investigar el comportamiento de aplicaciones sin necesidad de contar con su código fuente, rastrear llamadas a nivel de binarios nativos, inspeccionar metadatos, analizar aplicaciones empaquetadas (como Electron, Unity IL2CPP, Godot, etc.) y generar entornos de aprendizaje por refuerzo a partir de capturas de red.

Requisitos Documentados

Para ejecutar y utilizar REA, el código fuente y el paquete oficial especifican los siguientes requisitos de entorno:

- Node.js 22.x (>=22.23.4), 24.x (>=24.22.1) o 26.12.1+ (las versiones 23 y 25 no son compatibles).

- Gestor de paquetes npm.

- En sistemas operativos Linux, se requiere un comando `ps` compatible con `procps` en el `PATH` para verificaciones de propiedad de procesos.

- Para análisis nativo profundo, se requiere opcionalmente un motor externo como Hopper, Ghidra o IDA Pro.

Instalación y Configuración

El método oficial documentado para configurar REA con su agente de IA compatible es ejecutar el asistente de configuración mediante el comando:

npx rea-agents setup

Para instalar la herramienta de manera global y utilizarla directamente desde la terminal, ejecute:

npm install --global rea-agents
rea --help

Para actualizar una instalación global existente a la versión más reciente:

rea update

Uso

Una vez configurado el servidor MCP con su agente (compatible con Claude Code, Cursor, Gemini CLI, entre otros), puede solicitar investigaciones directamente en lenguaje natural:

Understand how search works in the Notes app, show me the evidence, and build a similar feature for my project.

Desde la línea de comandos, puede analizar directorios de aplicaciones JavaScript o paquetes Electron utilizando:

npx -y rea-agents@latest analyze-javascript-application /absolute/path/to/app --json

Ventajas

- Permite un análisis local y privado, donde los resultados devuelven evidencias concretas y limitaciones técnicas verificables.

- Soporta una amplia variedad de formatos de objetivos, incluyendo binarios nativos, artefactos de modelos (GGUF/safetensors), metadatos IL2CPP, paquetes APK de Android y código WebAssembly.

- Automatiza la creación de herramientas de agentes a partir de capturas de tráfico web (HAR) para construir entornos de prueba.

Limitaciones

- Las herramientas de análisis nativo avanzado dependen de software de terceros comercial (como IDA Pro o Hopper), cuyos costos de licencia y derechos de uso corren por cuenta del usuario.

- REA no otorga licencias, claves ni derechos de activación para herramientas comerciales de terceros.

- Las operaciones de tiempo de ejecución interactúan con los permisos del usuario local, por lo que se deben seguir directrices estrictas de uso responsable y legal.

Alternativas

Como alternativa editorial de comparación, se pueden mencionar herramientas tradicionales de ingeniería inversa y desensamblado como Ghidra (en solitario), Radare2, Frida o descompiladores independientes, aunque REA se diferencia por unificar el acceso mediante el protocolo MCP para agentes de IA.

Licencia y Precios

El código fuente original desarrollado para REA se distribuye bajo la licencia MIT. Respecto a los precios oficiales, el paquete y repositorio de REA son de código abierto y gratuitos; sin embargo, no incluye licencias de herramientas comerciales integradas (como IDA Pro u Hopper), las cuales poseen sus propias estructuras de precios ajenas a este proyecto.
