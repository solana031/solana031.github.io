awesome-gamedev-agent-skills: Habilidades de Desarrollo de Juegos para Agentes de IA

Una colección integral de habilidades para agentes de codificación de IA que abarca motores como Godot, Unity y Unreal, con un enrutador inteligente para cargar solo el contexto necesario.

Propósito

`awesome-gamedev-agent-skills` proporciona un conjunto estructurado de habilidades portátiles en formato `SKILL.md` (compatible con Claude Skills y el estándar abierto Agent Skills) diseñadas específicamente para asistentes de programación por IA. Su objetivo principal es permitir que un agente de IA comprenda las convenciones, las API y las estructuras de múltiples motores de videojuegos (Godot, Unity, Unreal, Phaser, PixiJS, three.js, Bevy, pygame, LÖVE, Defold y Roblox) mediante la carga automatizada y selectiva de contexto a través de un enrutador inteligente.

Requisitos

Para utilizar la herramienta CLI y automatizar la instalación de las habilidades, se requiere:

- Node.js versión 22.20 o posterior.

Para el desarrollo y la validación local de las habilidades, se utiliza un script de validación escrito en Python.

Instalación

La forma recomendada de instalar las habilidades es mediante el uso del paquete CLI universal de Node.js:

npx skills add gamedev-skills/awesome-gamedev-agent-skills

También es posible realizar una instalación alternativa utilizando los comandos de complementos de Claude Code:

claude plugin marketplace add gamedev-skills/awesome-gamedev-agent-skills
claude plugin install gamedev@awesome-gamedev-agent-skills

Uso

Una vez instaladas las habilidades en el directorio correspondiente de tu agente (por ejemplo, `.claude/skills/` o `.agents/skills/`), solo debes describir lo que deseas construir en lenguaje natural. El enrutador integrado analizará tu proyecto para detectar el motor utilizado y cargará exclusivamente las habilidades pertinentes (como física, movimiento, comportamiento o interfaces de usuario) sin saturar el contexto del agente.

Limitaciones

- El enrutador asume un motor principal exclusivo por proyecto para la selección base del motor.

- La compatibilidad de las rutas de instalación depende del agente de IA específico que estés utilizando.

- Las habilidades están versionadas frente a versiones concretas de los motores (por ejemplo, Godot 4.7, Unity 6.3 LTS), por lo que características de versiones muy diferentes podrían requerir ajustes manuales.
