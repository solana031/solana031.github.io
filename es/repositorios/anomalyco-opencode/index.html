Propósito

OpenCode es un agente de programación de código abierto diseñado para asistir en tareas de desarrollo mediante una interfaz de terminal y una aplicación de escritorio dedicada. Permite interactuar con repositorios de código utilizando capacidades de agentes especializados.

Requisitos

Dependiendo del método de instalación elegido, se requiere un gestor de paquetes compatible como npm, Homebrew, pacman, paru, mise o nix, o bien una terminal compatible con bash para el script de instalación automática.

Instalación

El paquete oficial ofrece múltiples métodos documentados para diferentes sistemas operativos:

curl -fsSL https://opencode.ai/v2/install | bash
npm i -g @opencode/cli@latest
brew install anomalyco/tap/opencode-v2
brew install opencode
sudo pacman -S opencode
paru -S opencode-beta
mise use -g opencode
nix run github:anomalyco/opencode

Para la aplicación de escritorio en macOS mediante Homebrew:

brew install --cask opencode-desktop

Uso y Agentes

OpenCode incluye agentes integrados entre los cuales se puede alternar utilizando la tecla `Tab`:

- **build**: El agente predeterminado con acceso completo para tareas de desarrollo.

- **plan**: Un agente de solo lectura diseñado para análisis y exploración de código, el cual deniega la edición de archivos por defecto y solicita confirmación antes de ejecutar comandos bash.

También cuenta con un subagente **general** para búsquedas complejas y tareas de múltiples pasos, invocable mediante `@general`.

Limitaciones

Las versiones anteriores a la 0.1.x deben eliminarse antes de proceder con una nueva instalación. La versión de escritorio se encuentra actualmente en fase BETA.

Licencia y Precios

OpenCode se distribuye bajo la licencia MIT. Las reclamaciones de upstream no especifican precios comerciales verificados, por lo que el precio oficial no está disponible en la documentación analizada.

Alternativas

Como agente de código open source interactivo en terminal y escritorio, compila características similares a otras herramientas de asistencia de IA para desarrolladores, destacándose por su arquitectura de agentes especializados como 'build' y 'plan'.
