Propósito

VoiceStudio es una aplicación de código abierto diseñada para ejecutar flujos de trabajo de voz íntegramente de manera local en tu hardware. Su propósito principal es ofrecer una alternativa privada y autohospedada a herramientas comerciales de síntesis de voz, permitiendo a los usuarios realizar clonación de voz, diseño de voces artificiales, doblaje de videos con sincronización de tiempos, transcripción, dictado mediante un widget flotante y creación de audiolibros en 646 idiomas. El sistema está optimizado para funcionar mediante motores locales como OmniVoice o CosyVoice, eliminando la dependencia obligatoria de servicios remotos en la nube y garantizando el control absoluto de los datos de audio.

Requisitos del Sistema y Requisitos previos

Los requerimientos de hardware varían dependiendo del motor de voz seleccionado:

- **GPU NVIDIA (Windows / Linux):** Soporta aceleración por CUDA.

- **Apple Silicon:** Soporta aceleración por Metal (MPS).

- **GPU AMD:** Compatible opcionalmente con CosyVoice GGUF usando Vulkan cuando la plataforma se compila con dicho soporte.

- **Sin GPU dedicada:** Es totalmente utilizable en CPU (con menor velocidad), instalando automáticamente la versión ligera de PyTorch que requiere aproximadamente 5 GB de espacio libre en disco.

- **Windows en ARM:** Soporte experimental en fase de validación.

- **Mac Intel:** Limitado a la interfaz gráfica de escritorio conectada a un backend remoto.

Para instalaciones desde el código fuente o mediante scripts de compilación avanzada, se requiere contar con Git, Node.js 22 o superior, Bun, Rust/Cargo y las herramientas de compilación nativas del sistema operativo.

Instalación

La instalación documentada para macOS y Linux se realiza mediante un script ejecutable directo desde la terminal:

curl -fsSL https://voicestudio.sh/install | sh

Si deseas instalar una versión específica de la aplicación de escritorio basada en Electron, puedes indicar la etiqueta correspondiente:

curl -fsSL https://voicestudio.sh/install | sh -s -- --version X.Y.Z

En sistemas Windows, el comando equivalente que debe ejecutarse dentro de PowerShell es:

irm https://voicestudio.sh/install | iex

Si el dominio principal no se encuentra disponible, es posible recurrir directamente al repositorio oficial para descargar el script de instalación:

curl -fsSL https://raw.githubusercontent.com/debpalash/VoiceStudio/main/scripts/install.sh | sh

Uso

Una vez instalada y abierta la aplicación de escritorio Electron, selecciona la sección de **Clonación de voz**. Desde allí puedes elegir una voz predeterminada o añadir una grabación de referencia limpia. Introduce el texto deseado y genera el audio. La primera vez que utilices un motor o modelo específico, la interfaz te guiará para descargar los archivos necesarios automáticamente. También cuentas con espacios de trabajo dedicados al diseño de voz, subtitulado y doblaje de video.

Ventajas

- Funciona de manera completamente local, protegiendo la privacidad de los datos de audio.

- Soporta una amplísima variedad de 646 idiomas.

- Ofrece múltiples herramientas integradas como clonación, transcripción, dictado y creación de audiolibros en una sola aplicación.

- Soporte para aceleración mediante hardware moderno (CUDA, Metal).

Limitaciones

- El procesamiento en equipos sin tarjeta gráfica dedicada o con gráficos integrados antiguos puede ser considerablemente lento.

- Las versiones para arquitecturas como Windows en ARM o Mac con procesadores Intel presentan limitaciones operativas documentadas.

- Los pesos de los modelos de IA y los archivos de voz requieren espacio significativo de almacenamiento local.

Alternativas y Comparativa Editorial

Como alternativas comerciales del sector se encuentran servicios centralizados en la nube como ElevenLabs. En comparación con ellos, VoiceStudio destaca por ser de código abierto, ejecutarse de forma local sin requerir suscripciones de pago por uso y mantener la privacidad de los datos del usuario. Frente a otras herramientas puramente de línea de comandos, VoiceStudio destaca por ofrecer una interfaz gráfica de usuario en Electron y aplicaciones móviles preliminares.
