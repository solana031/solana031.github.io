Qué es y para qué sirve

Bland AI proporciona infraestructura para agentes telefónicos. Su integración oficial conecta clientes compatibles con herramientas de llamadas, mensajes y gestión de conversaciones. El Reel fue una pista de descubrimiento; las afirmaciones de esta guía proceden de documentación y páginas de Bland. No hemos ejecutado llamadas ni contratado un plan.

Claude Code, MCP y API

Bland documenta un servidor MCP remoto en https://api.bland.ai/v1/mcp. Claude Code puede usar la integración para trabajar con una organización autorizada. Conectarlo no convierte por sí solo una instrucción en una llamada: hacen falta autenticación, herramientas disponibles y aprobación de acciones con efectos externos. Los tokens OAuth de MCP no sirven para la API REST. Para REST, consulta la autenticación específica de Bland.

Instalación y primeros pasos

La CLI oficial requiere Node.js 18 o posterior. Sus instrucciones incluyen estos comandos, que aquí se documentan sin ejecutarlos:

npm install -g bland-cli
bland auth login --device
bland mcp

La segunda orden inicia un flujo de autorización en el navegador. El tercero ejecuta el servidor MCP local de la CLI. Es una alternativa al servidor remoto; no hay que instalar ambos para describir la integración. Revisa los permisos y guarda credenciales fuera del código.

Agent Phone Plan

Bland ofrece un número estadounidense dedicado para el agente, con voz y SMS dirigidos a Estados Unidos y Canadá, sujeto a uso razonable y una llamada concurrente. No debe presentarse como un plan para llamar a España. El titular elige y aprueba la suscripción; esta guía no inicia ese proceso.

Costes y discrepancias

La página comercial anuncia una promoción inicial y después una cuota mensual. La página para agentes muestra otra presentación del precio y límites diferentes de frecuencia. Ambas fuentes están enlazadas: confirma las condiciones vigentes en el panel antes de comprar. No trasladamos esas diferencias a una cifra universal ni prometemos llamadas sin restricciones.

Casos de uso y límites

Consultar disponibilidad o tramitar una solicitud son ejemplos de tareas posibles; su éxito depende del diseño y de los permisos. Frente a programar directamente REST, MCP ofrece herramientas desde el cliente del agente, mientras REST permite integración propia. Ninguna vía elimina costes, controles o responsabilidad. Bland no presenta esta compatibilidad como una asociación o respaldo de Anthropic. Para ampliar la guía, usa la documentación oficial; no atribuimos a Bland un repositorio público ni una licencia de código abierto no corroborados.
