Whiteboard Animation VI: Animaciones de Pizarra Guiadas por IA

Una guía completa sobre Whiteboard Animation VI, una aplicación local basada en Gradio desarrollada en Vietnam que transforma ilustraciones en animaciones de pizarra con coloración de sujetos primero, agrupaciones de color y manos reales animadas.

Propósito

Whiteboard Animation VI es una herramienta local basada en Gradio desarrollada para convertir imágenes ilustradas en animaciones de estilo pizarra. Combina la coloración centrada en el sujeto, agrupaciones de colores en el espacio Lab, límites de región conscientes de la tinta y manos fotográficas en movimiento. Permite priorizar la aparición de los personajes principales antes de rellenar los fondos y exportar los resultados directamente en formato MP4.

Requisitos del Sistema y Entorno

Se requiere utilizar Python 3.11 o 3.12 de 64 bits en sistemas Windows. Para el procesamiento mediante NVIDIA CUDA, es necesario contar con un controlador compatible de NVIDIA y el paquete opcional `PyNvVideoCodec` si se desea utilizar la codificación NVENC. Por otro lado, la exportación estándar por CPU utiliza `libx264` y requiere que FFmpeg esté disponible en el `PATH` del sistema.

Instalación

Ejecute los siguientes comandos de PowerShell desde el directorio del repositorio clonado para configurar el entorno virtual e instalar las dependencias:

py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip

Para habilitar el soporte con aceleración por GPU CUDA, instale los componentes específicos de PyTorch y las dependencias de GPU:

.\.venv\Scripts\python.exe -m pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r requirements-gpu.txt

En caso de utilizar exclusivamente la CPU, emplee los siguientes comandos:

.\.venv\Scripts\python.exe -m pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

Adicionalmente, se debe descargar el modelo de segmentación de sujetos requerido antes de utilizar dicha característica:

.\.venv\Scripts\python.exe scripts\download_model.py

Uso y Ejecución Local

Puede iniciar la interfaz local ejecutando el archivo por lotes `start.bat` o mediante PowerShell:

.\start.ps1
.\start.ps1 -Port 7861

Si prefiere ejecutar el servidor en primer plano con la interfaz de consola:

.\.venv\Scripts\python.exe app.py --port 7860 --open --log

También es posible integrar el renderizado directamente dentro de un script de Python:

import numpy as np
from PIL import Image
from handdraw.settings import Settings
from handdraw.render import render_video

image = np.asarray(Image.open("input.png").convert("RGBA"))
settings = Settings(mode="e", duration=10, draw_percent=70, ink_percent=45)
video_path, report = render_video(image, settings)

Ventajas

- Separación de primer plano mediante ISNet (SkyTNT Anime Segmentation) para mantener los personajes visibles desde el inicio.

- Enrutamiento optimizado para reducir viajes innecesarios entre trazos conservando el orden de los sujetos.

- Caché integrada para reutilizar planes de imagen recientes al ajustar la temporalidad o los parámetros de las manos.

- Interfaz local privada que deshabilita las analíticas públicas y opera estrictamente en bucle local (`127.0.0.1`).

Limitaciones

- Las operaciones de red para descargar los pesos del modelo tienen un límite estricto de tiempo de espera sin reintentos automáticos.

- Las ilustraciones de muestra incluidas en la documentación oficial poseen restricciones de licencia independientes y requieren verificación antes de su redistribución.

- El renderizado se procesa de forma serializada con una cola máxima de hasta ocho tareas pendientes.

Comparativa Editorial y Alternativas

A diferencia de las herramientas de animación de pizarra basadas en la nube que imponen cuotas de renderizado o suscripciones recurrentes, Whiteboard Animation VI ofrece una solución de código abierto totalmente local que aprovecha la aceleración por hardware local (CUDA/NVENC o CPU). Otras alternativas comerciales o en la nube otorgan menos control sobre la segmentación por IA basada en trazos de tinta y el orden de los grupos de colores.
