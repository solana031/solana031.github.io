Propósito

DeepSeek Harness (`dsh`) es un arnés de agentes de código abierto desarrollado por DeepSeek AI. Está construido bajo una arquitectura donde "todo es un plugin" y funciona gracias a Cordis, cuyo diseño se describe en el artículo _A Programming Paradigm for Spatiotemporal Composability_.

Requisitos y Configuración

El proyecto se encuentra en una fase de vista previa para desarrolladores y está sujeto a cambios que pueden romper la compatibilidad. Se recomienda revisar los avisos de seguridad antes de ejecutar el código. Para la ejecución básica, se requiere contar con Node.js instalado en el sistema.

Instalación

Para ejecutar el proyecto directamente mediante npm o clonando el repositorio fuente, puedes utilizar los siguientes comandos provistos por la documentación oficial:

npx @deepseek-ai/dsh web

O bien, si prefieres clonar el repositorio y compilarlo de forma local:

git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web

Uso

El comando inicia una interfaz web en `http://127.0.0.1:3080` de manera predeterminada y la abre en el navegador web local. Si se ejecuta en un entorno SSH, solo imprimirá la URL del host. Es posible pasar el argumento `--no-open` para iniciar el servidor sin abrir el navegador automáticamente.

Limitaciones

Al encontrarse en una etapa de vista previa para desarrolladores, el software experimenta iteraciones rápidas que pueden provocar cambios incompatibles entre versiones. Además, requiere un manejo cuidadoso de las dependencias y configuraciones descritas en las notas de seguridad.

Alternativas y Comparativa

Como marco de trabajo para agentes basado en una arquitectura modular de plugins, se diferencia de otros entornos tradicionales al delegar la extensibilidad por completo a un sistema impulsado por Cordis, ofreciendo una alta composibilidad espaciotemporal.
