Introducción y propósito

El propósito de esta guía es enseñar a cualquier persona que esté abriendo su terminal por primera vez cómo configurar, administrar y operar Memanto para centralizar el almacenamiento y el razonamiento de las memorias de múltiples agentes de IA. Un caso de uso concreto es registrar una decisión de arquitectura mediante la terminal utilizando `memanto remember` con un agente de desarrollo, y permitir que un agente de revisión de código diferente consulte esa misma información días después sin duplicar bases de datos ni perder el contexto histórico.

Qué es y cómo funciona

Memanto no es una simple biblioteca de API o un almacén vectorial pasivo; funciona como un agente secundario o "jefe de personal" que opera junto a tu flota de agentes de inteligencia artificial. Mientras que las plataformas tradicionales simplemente guardan cadenas de texto en bases de datos (creando silos desconectados), Memanto observa flujos de interacción, extrae conocimiento estructurado, consolida duplicados, reconcilia contradicciones de forma versionada en lugar de sobrescribirlas ciegamente, aplica políticas de expiración y suministra resúmenes mínimos y relevantes a tus agentes antes de que ejecuten cualquier acción.

El motor de recuperación utiliza un enfoque semántico respaldado por contenedores locales o servicios en la nube opcionales, permitiendo interoperabilidad a través del formato abierto Open Knowledge Format (OKF).

Cuándo usarlo

- Cuando operas múltiples herramientas o entornos de agentes (como Claude Code, Cursor y scripts personalizados) y necesitas que compartan un estado de conocimiento coherente.

- Cuando necesitas gestionar caducidades de memoria y políticas de retención formales para evitar que la acumulación de datos históricos genere ruido o contradicciones no resueltas en tus flotas.

- Cuando requieres auditoría estricta de las decisiones tomadas por tus agentes, con marcas de tiempo, puntuaciones de confianza y trazabilidad completa de cada creencia almacenada.

Lo que necesitas

Para ejecutar Memanto en modo local (On-Prem), se requiere tener instalado Docker y un entorno de tiempo de ejecución compatible. Para la instalación mediante Python, necesitas pip y acceso a una terminal de comandos en sistemas operativos compatibles (macOS, Linux o Windows). No hay requerimientos de cuentas o claves de API obligatorios en el modo local.

Dónde conseguirlo

El repositorio oficial del proyecto y código fuente se encuentra en GitHub bajo la ruta `moorcheh-ai/memanto` (https://github.com/moorcheh-ai/memanto), con descargas de paquetes disponibles a través de PyPI (`memanto`), npm (`@moorcheh-ai/memanto`) y Go (`github.com/moorcheh-ai/memanto/sdks/go`).

Instalación

La instalación inicial del paquete de Python se realiza directamente desde la terminal ejecutando el comando de gestión de paquetes estándar:

pip install memanto

Una vez instalado el paquete base, puedes inicializar la configuración ejecutando el comando principal sin argumentos en tu terminal local:

memanto

Este comando interactivo te guiará para seleccionar entre el modo "On-Prem" (que configura Docker y Ollama de manera local sin requerir cuentas externas) o el modo "Cloud" mediante una clave gratuita de API.

Primer uso paso a paso

1. Conecta tu entorno de desarrollo o agente preferido ejecutando el comando de integración correspondiente en la terminal:

memanto connect claude-code

Este comando vincula la interfaz de tu agente para que comience a compartir el estado administrado.

2. Registra un nuevo fragmento de conocimiento estructurado especificando su tipo en la terminal:

memanto remember "Auth migrated to JWT — session cookies deprecated" --type decision

Este comando guarda la decisión de manera tipada dentro del espacio de nombres activo.

3. Consulta la memoria registrada desde cualquier otro agente o sesión utilizando una orden de recuperación:

memanto recall "how does auth work"

Este comando busca semánticamente en el almacenamiento y devuelve el contexto relevante.

4. Genera una respuesta fundamentada directamente a partir del contexto recuperado sin consumir claves de API externas adicionales:

memanto answer "why did we drop session cookies?"

Este comando procesa la pregunta y extrae la respuesta exacta basada en la memoria previamente guardada.

Errores comunes y cómo solucionarlos

- **Fallo al conectar con el backend local:** Si utilizas el modo On-Prem y obtienes errores de comunicación, verifica que el servicio de Docker esté activo y que los contenedores necesarios estén ejecutándose en tu máquina.

- **Dependencias de versión en integraciones MCP:** Si experimentas errores al interactuar con herramientas del protocolo MCP, asegúrate de utilizar una versión del paquete igual o superior a la especificada en los requerimientos del proyecto (`memanto>=0.2.31`).

Limitaciones

- Las puntuaciones y métricas de rendimiento publicadas en los puntos de referencia de recuperación (como LongMemEval o LoCoMo) dependen fuertemente de los modelos de lectura y jueces utilizados, por lo que deben interpretarse de forma direccional y no absoluta.

- El comportamiento de expiración automática requiere la habilitación explícita de rutinas programadas mediante la orden de programación diaria; de lo contrario, las memorias no caducarán por sí solas.

Alternativas y cómo se compara

A diferencia de almacenes vectoriales tradicionales (como bases de datos con SDKs de incrustación) que solo se dedican a persistir datos mediante operaciones básicas de escritura y recuperación, Memanto actúa como un agente autónomo capaz de curar, consolidar, expirar y reconciliar contradicciones de forma estructurada. Frente a otras herramientas de memoria para agentes, ofrece un formato de intercambio abierto basado en Markdown legible (Open Knowledge Format) que evita el bloqueo con un proveedor específico.

Preguntas frecuentes

- **¿Es necesario tener una cuenta o clave de API para usar Memanto?** No. En el modo local (On-Prem) puedes operar completamente sin cuentas ni claves externas utilizando Docker y un motor local como Ollama.

- **¿Qué sucede cuando dos agentes tienen creencias contradictorias?** Memanto no sobrescribe la información de forma silenciosa; en su lugar, versiona ambas creencias y superficie la contradicción para su posterior revisión y resolución.

- **¿Cómo se exportan los datos almacenados?** Puedes exportar todo el estado de la memoria estructurada en formato Markdown portable utilizando el comando de exportación con soporte para el formato OKF.

Evaluación editorial

### Para quién es

Es ideal para desarrolladores de sistemas multi-agente, ingenieros de plataformas de IA y equipos técnicos que buscan soberanía sobre sus datos, trazabilidad completa de las decisiones y una gestión automatizada del ciclo de vida de la memoria entre diferentes herramientas de desarrollo.

### Quién debe saltárselo

Debe ser evitado por desarrolladores que buscan una base de datos vectorial tradicional de bajo nivel para consultas brutas sin lógica de agentes, o por quienes operan estrictamente en ecosistemas cerrados donde las herramientas nativas de plataforma son un requisito obligatorio.
