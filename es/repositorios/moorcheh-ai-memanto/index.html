Propósito y Caso de Uso

El propósito de Memanto es actuar como un agente de memoria independiente que administra, consolida y concilia el conocimiento de otras flotas de agentes de IA en lugar de limitarse a almacenar datos planos. Un caso de uso concreto consiste en permitir que un agente de desarrollo en Claude Code recuerde y aplique una decisión de arquitectura o cambio de autenticación registrado previamente por otro agente de backend, evitando así contradicciones en el equipo de desarrollo.

Cuándo Usarlo

Debes utilizar Memanto cuando operes múltiples agentes de IA en diferentes plataformas (como Claude Code, Cursor o Windsurf) y necesites que compartan un conocimiento unificado sin perder el contexto histórico, resolver contradicciones automáticamente o expirar información obsoleta mediante políticas definidas.

Lo Que Necesitas

Para ejecutar Memanto en tu máquina local, necesitas una terminal de comandos, Python instalado (según los paquetes oficiales de PyPI) y opcionalmente Docker junto con Ollama si deseas operar completamente en modo local sin una cuenta externa.

Dónde Obtenerlo

El repositorio oficial del proyecto y código fuente se encuentra en GitHub bajo la ruta `moorcheh-ai/memanto`, y el paquete principal está disponible en PyPI como `memanto`.

Instalación

Para instalar el paquete oficial en tu entorno local, ejecuta el siguiente comando en tu terminal:

pip install memanto

Primer Uso

Una vez instalado el paquete, puedes iniciar la configuración inicial ejecutando el siguiente comando en tu terminal para elegir entre el modo local con Docker y Ollama o el modo en la nube con clave de API gratuita:

memanto

Este comando te guiará de manera interactiva a través de la configuración inicial del sistema de memoria en tu propia máquina.

Limitaciones

Memanto depende de un motor de recuperación semántica que requiere recursos locales si se ejecuta en modo completamente desconectado (On-Prem con Docker y Ollama). Asimismo, los puntajes en benchmarks públicos de recuperación pueden variar dependiendo del modelo lector o de los parámetros de evaluación utilizados, por lo que deben interpretarse de forma direccional.

Licencia y Precios

El software se distribuye bajo la licencia MIT. Respecto a los precios oficiales, el paquete ofrece un modo local gratuito y un nivel en la nube gratuito que proporciona 100,000 operaciones gratuitas mediante clave de API; no se dispone de información de precios comerciales verificados adicionales en la documentación oficial.
