Propósito

ChatCut Agent Plugins conecta herramientas de IA populares como Codex, Claude Code, Grok Bot, Cursor y Kimi Work directamente con ChatCut. Su finalidad principal es permitir la edición de proyectos de video mediante asistencia de inteligencia artificial. Según las afirmaciones del repositorio ascendente, los usuarios pueden importar medios, modificar líneas de tiempo, generar elementos gráficos, transcribir audio, añadir subtítulos y exportar proyectos de video completos.

Requisitos

Para utilizar correctamente estos complementos, el paquete oficial documenta los siguientes requisitos:

- Una cuenta activa en ChatCut.

- Una plataforma compatible con soporte para complementos: Codex, Claude Code 2.x (CLI o aplicación de escritorio), Grok Bot, Cursor o Kimi Work.

- Acceso directo a un proyecto existente en ChatCut que se desee editar.

Instalación y Configuración

Las instrucciones de instalación varían según el host seleccionado:

- Para Codex, visite [chatcut.io/chatgpt](https://chatcut.io/chatgpt).

- Para Claude Code, consulte [chatcut.io/claude](https://chatcut.io/claude) o revise la copia ejecutable en la documentación del repositorio.

- Para Grok Bot y Cursor, siga las guías ubicadas en el archivo README del directorio grok.

Autenticación

El complemento se comunica con ChatCut empleando el punto de acceso MCP alojado:

https://api.chatcut.io/api/external-mcp/mcp

La autenticación se realiza mediante comandos específicos de cada entorno, tales como:

codex mcp login chatcut

o bien:

claude mcp login plugin:chatcut:chatcut

En el caso de Grok Bot y Cursor, el flujo de autorización debe completarse desde la pantalla de complementos de la propia aplicación anfitriona.

Uso y Ejemplos

Una vez completada la instalación y la autenticación, es posible interactuar mediante el lenguaje natural con los agentes de IA utilizando instrucciones como:

- Importar un video al proyecto actual de ChatCut.

- Agregar superposiciones de gráficos en movimiento.

- Generar locuciones y música de fondo.

- Transcribir clips y añadir subtítulos automáticamente.

- Exportar el proyecto finalizado.

Limitaciones

El uso está estrictamente limitado a las plataformas de asistencia de agentes compatibles y requiere obligatoriamente una conexión funcional a internet para interactuar con el punto final MCP alojado en la API de ChatCut.

Comparativa Alternativa

A diferencia de las interfaces gráficas tradicionales que exigen manipulación manual de la línea de tiempo, ChatCut Agent Plugins prioriza la automatización conversacional mediante múltiples agentes, ofreciendo adaptadores específicos para entornos variados como Codex, Claude, Grok y Kimi frente a soluciones propietarias de un solo editor.
