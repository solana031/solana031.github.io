Propósito y caso de uso

Este documento proporciona una guía editorial independiente para comenzar a utilizar Postiz con el fin de programar contenido digital de manera centralizada. Un caso de uso típico consiste en planificar publicaciones semanales para varias plataformas sociales desde una sola interfaz web o mediante agentes de inteligencia artificial conectados.

Qué es Postiz y cómo funciona

Postiz es una plataforma de gestión de redes sociales diseñada para programar, automatizar y analizar contenido. Su arquitectura se basa en un monorepo gestionado con pnpm workspaces, utilizando tecnologías web modernas como NextJS para la interfaz de usuario en React, NestJS para el backend, Prisma ORM configurado por defecto con PostgreSQL, Temporal para la orquestación de flujos y Resend para las notificaciones por correo electrónico.

El sistema funciona mediante una separación clara entre la interfaz web y la infraestructura local o en la nube. En una instalación autohospedada, el software opera en tu propio servidor ejecutando contenedores o servicios configurados mediante variables de entorno, comunicándose directamente con las plataformas sociales a través de flujos de autenticación oficiales OAuth, sin almacenar claves de API de terceros en servidores intermedios.

Cuándo usarlo

- Cuando necesitas gestionar y programar publicaciones de forma centralizada en redes como X, LinkedIn, YouTube, Instagram, TikTok o Reddit.

- Cuando buscas una alternativa autohospedable de código abierto para mantener el control total de tus datos de marketing bajo la licencia AGPL-3.0.

- Cuando deseas integrar la automatización de contenidos con herramientas de flujos de trabajo como n8n, Make.com o agentes de IA mediante Model Context Protocol (MCP).

Qué necesitas

Para ejecutar la versión de código abierto de Postiz en tu propia infraestructura, necesitas un servidor con soporte para Docker o herramientas de despliegue como Coolify o Railway. Asimismo, debes contar con bases de datos compatibles (como PostgreSQL), Redis para colas y almacenamiento configurado. Para acceder a funciones avanzadas de IA o publicar en plataformas específicas, debes proporcionar tus propias claves de API de proveedores como OpenAI o registrar tus propias aplicaciones de desarrollador en las redes sociales correspondientes.

Dónde obtenerlo

El código fuente oficial y los paquetes de la aplicación se encuentran en el repositorio de GitHub de `gitroomhq/postiz-app`. La documentación oficial está disponible en docs.postiz.com y el sitio web comercial en postiz.com.

Instalación

La instalación local depende de la infraestructura elegida (Docker, VPS o plataformas como Coolify). Debido a que los pasos específicos de configuración de contenedores y variables de entorno varían y no se detallan por completo en el paquete de referencia rápido más allá de seguir la guía oficial de inicio rápido, se recomienda consultar la documentación de despliegue en docs.postiz.com o permitir que un asistente de lenguaje asista en la configuración de las variables de entorno necesarias para PostgreSQL, Redis y el almacenamiento.

Primer uso paso a paso

1. Despliega la instancia de Postiz en tu servidor local o accede a Postiz Cloud a través de platform.postiz.com.

2. Abre la interfaz web de la aplicación en tu navegador web.

3. Configura tu cuenta de usuario e inicia sesión en el panel de control principal.

4. Conecta tus cuentas de redes sociales utilizando los flujos de autenticación OAuth oficiales provistos por cada plataforma.

5. Crea tu primera publicación seleccionando las redes de destino, redactando el texto o añadiendo contenido multimedia, y elige una fecha y hora para programarla.

Errores comunes y solución

- **Falla en la autenticación con redes sociales:** Asegúrate de haber configurado correctamente tus propias credenciales de desarrollador si utilizas la versión autohospedada, o verifica que las redirecciones OAuth estén permitidas.

- **Problemas de conexión con la base de datos:** Revisa que las variables de entorno para PostgreSQL y Redis estén definidas correctamente y que los servicios contenedores estén en ejecución.

- **Vulnerabilidades de seguridad:** Actualiza inmediatamente a versiones recientes (como v2.25.3 o superiores) para solucionar avisos de seguridad conocidos como PSA-2026-E9AHFV y PSA-2026-YT2HMH.

Limitaciones

- La versión autohospedada requiere que crees tus propias aplicaciones de desarrollador en plataformas como Meta, YouTube o TikTok, lo cual puede demorar varios días según la aprobación de cada proveedor.

- El mantenimiento, las copias de seguridad, los parches de seguridad y las actualizaciones de imágenes en la edición de código abierto son responsabilidad exclusiva del usuario.

- Las cuotas de IA dependen de las claves de API que proporciones por tu cuenta en la versión autohospedada.

Alternativas y comparación

- **Postiz Cloud:** Ofrece una experiencia totalmente gestionada con aplicaciones preaprobadas para cada canal y cuotas mensuales incluidas, frente a la necesidad de configurar infraestructura propia en la edición de código abierto.

- Otras herramientas comerciales de gestión social como Buffer o Hootsuite ofrecen SaaS cerrados, mientras que Postiz destaca por su enfoque de código abierto bajo AGPL-3.0 y su compatibilidad con agentes de IA.

Preguntas frecuentes

**¿Postiz almacena mis credenciales de redes sociales?**

No. Postiz utiliza flujos OAuth oficiales de cada plataforma y nunca solicita ni almacena claves de API o tokens de acceso de los usuarios en servidores alojados.

**¿Cuál es la diferencia entre Postiz Cloud y la versión de código abierto?**

Ambas ofrecen las mismas características principales, pero Cloud es gestionada por el proveedor con aplicaciones aprobadas y suscripciones por planes, mientras que la versión de código abierto es gratuita bajo AGPL-3.0 y requiere tu propia infraestructura.

**¿Qué licencia utiliza el proyecto?**

El código fuente disponible en el repositorio oficial se distribuye bajo la licencia AGPL-3.0.

**¿Cuál es el precio de la edición autohospedada?**

El software de código abierto es gratuito (AGPL-3.0); solo pagas los costos de la infraestructura que utilices para alojarlo.

Evaluación editorial

Postiz es una solución excelente para desarrolladores, equipos técnicos y profesionales del marketing digital que desean una herramienta avanzada de programación social con capacidades de automatización e inteligencia artificial, manteniendo el control total de sus datos mediante una arquitectura autohospedada. Deben omitir esta herramienta los usuarios sin experiencia técnica en administración de servidores o aquellos que prefieren una solución SaaS comercial tradicional sin la necesidad de configurar aplicaciones de desarrollador en redes sociales.
