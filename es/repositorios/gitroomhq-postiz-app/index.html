Propósito

Postiz es una plataforma de gestión de redes sociales diseñada para programar, automatizar y analizar contenido en múltiples canales. Integra capacidades agénticas con inteligencia artificial y herramientas de automatización como N8N, Make.com o Zapier mediante su API pública y SDKs.

Requisitos y Configuración

El proyecto está desarrollado utilizando un monorepo con espacios de trabajo Pnpm, NextJS para el frontend, NestJS para el backend, Prisma como ORM predeterminado para PostgreSQL, Temporal para flujos de trabajo y Resend para notificaciones por correo electrónico.

Para poner en marcha la edición autoalojada, los usuarios deben desplegar la aplicación utilizando Docker, Coolify, Railway o cualquier VPS compatible, configurando manualmente las variables de entorno, la base de datos PostgreSQL, Redis y el almacenamiento.

Uso

Los usuarios pueden interactuar con Postiz a través de una interfaz de calendario para planificar publicaciones, colaborar con miembros del equipo, configurar publicaciones automáticas mediante RSS y conectar agentes de inteligencia artificial y superficies agénticas (como ChatGPT, Claude, Cursor, MCP y herramientas CLI).

Ventajas

- Soporta una amplia variedad de redes sociales y canales de mensajería (Instagram, YouTube, LinkedIn, X, TikTok, Discord, Mastodon, Bluesky, entre otros).

- Ofrece la misma funcionalidad central tanto en su versión en la nube como en la edición de código abierto autoalojada.

- Sin límites artificiales de canales, publicaciones mensuales o miembros del equipo en la versión autogestionada.

- Integración directa con flujos de trabajo de IA y herramientas de automatización.

Limitaciones

- La configuración y el mantenimiento de la infraestructura recaen por completo en el usuario en la versión autoalojada.

- La creación y aprobación de aplicaciones de desarrollador en plataformas sociales de terceros (como Meta, YouTube o TikTok) puede requerir semanas de trámite.

- Las funciones avanzadas de IA (como cuotas de generación de imágenes, videos y copilotaje) requieren claves de API propias en la edición autoalojada.

Alternativas y Comparativa Editorial

Existen diferencias clave entre Postiz Cloud y la edición de código abierto autoalojada:

- **Postiz Cloud:** Servicio gestionado por suscripción con prueba gratuita de 7 días, aplicaciones preaprobadas para canales y cuotas de IA gestionadas.

- **Postiz Open-Source (Self-Hosted):** Gratuita bajo licencia AGPL-3.0 de forma indefinida; el usuario paga únicamente por su propia infraestructura y gestiona sus propias claves de API y credenciales de aplicaciones sociales.

Licencia y Precios

El código fuente de este repositorio está disponible bajo la licencia AGPL-3.0. Para Postiz Cloud, las tarifas de suscripción varían según el plan contratado en su sitio oficial, mientras que la edición autoalojada no incluye precios verificados específicos más allá de los costes de infraestructura propios del usuario.
