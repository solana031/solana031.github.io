ECC: El Sistema de Optimización de Rendimiento para Harness de Agentes

ECC es un sistema operativo de ingeniería para harnesses de agentes como Claude Code, Codex y Kimi Code. Optimiza la ventana de contexto permitiendo planificar, probar y verificar código antes de construirlo, mediante un enfoque open-source basado en habilidades, agentes especializados y herramientas de seguridad.

Propósito y Funcionalidad

ECC (The agent harness performance optimization system) proporciona a tu agente de IA un sistema de ingeniería coordinado y una caja de herramientas completa. Ayuda al modelo a planificar antes de construir, verificar cambios mediante pruebas automatizadas, revisar su propio trabajo desde un contexto fresco, recordar lo que importa y convertir victorias repetidas en habilidades y flujos de trabajo reutilizables. En lugar de reconstruir este proceso en cada prompt, ECC se instala una vez para integrarse directamente en el funcionamiento del agente.

Requisitos del Sistema y del Entorno

El sistema requiere Node.js 18 o superior para el paquete universal. Para la configuración de plugins en Claude Code, también se necesitan Git y Claude Code 2.1 o una versión más reciente disponible en la ruta del sistema (`PATH`).

Instalación Documentada

La forma recomendada de instalar ECC utilizando la configuración guiada universal es la siguiente:

npx ecc-universal@2.2.3 setup

Si prefieres ejecutar una instalación guiada multiplataforma para varios harnesses (como Claude Code, Codex y Kimi Code), utiliza el siguiente comando:

npx ecc-universal@2.2.3 install --guided

Para una instalación con bajo consumo de contexto y sin tiempo de ejecución de ganchos (hooks):

npx ecc-universal@2.2.3 install --profile minimal --target claude

Uso y Comandos Principales

ECC se basa principalmente en habilidades, pero incluye comandos y agentes especializados:

- Creación de características: `/ecc:plan "describir característica"` seguido de flujos de prueba (TDD).

- Corrección de errores: Reproducir mediante una prueba fallida y aplicar el flujo de desarrollo guiado por pruebas.

- Revisión de código: `/code-review` para verificaciones de contexto fresco.

- Análisis de seguridad: `/security-scan` o utilizando la herramienta AgentShield integrada.

Ventajas y Limitaciones

Ventajas:

- Optimiza la ventana de contexto persistiendo información crucial.

- Soporta múltiples harnesses como Claude Code, Codex, Qoder, Cursor, OpenCode y Kimi Code.

- Incluye un catálogo masivo de agentes especializados, habilidades y análisis de seguridad con AgentShield.

Limitaciones:

- No todos los harnesses soportan la paridad completa de características; por ejemplo, adaptadores avanzados dependen de matrices de ciclo de vida específicas.

- Algunos comandos avanzados como los prefijados con `multi-*` requieren la instalación externa de dependencias como `ccg-workflow`.

Alternativas y Comparativa Editorial

Como sistema de control y optimización para asistentes de programación basados en IA, ECC destaca por su enfoque estructurado de ingeniería frente a configuraciones manuales dispersas o prompts sueltos. A diferencia de plugins simples que solo añaden comandos aislados, ECC implementa una arquitectura completa de bucles de ejecución, memoria, habilidades y seguridad.
