Money Agent: un experimento de IA que no puede mentir sobre el dinero

Money Agent es un experimento de investigación que explora si un agente autónomo de IA puede generar ingresos reales, verificando sus afirmaciones mediante un verificador externo que el agente no puede manipular. El repositorio documenta el proceso, los resultados y las lecciones aprendidas.

Propósito

Money Agent es un experimento de investigación diseñado para responder una pregunta simple: ¿puede un agente de IA autónomo, dado una tarjeta y una vía de pago, generar dinero real? Sin embargo, el enfoque principal no es solo ganar dinero, sino establecer un marco de verificación confiable. El agente produce afirmaciones (por ejemplo, "Gané $X"), y un verificador externo, que el agente no puede invocar, calcula los hechos reales basados en la API de Stripe y la alimentación de la tarjeta.

Requisitos y configuración

Para ejecutar el experimento en modo simulado (sin dinero ni claves), se necesita clonar el repositorio y ejecutar el script de simulación. Para una ejecución en vivo, se requiere una cuenta de Stripe, claves restringidas, una tarjeta con límite de gasto y un verificador en una máquina separada. La configuración detallada se documenta en `SETUP.md` y en el manual del operador `docs/runbooks/RUN2_OPERATOR_RUNBOOK.md`.

Uso

Para probar el sistema sin necesidad de una cuenta de Stripe, se puede ejecutar la simulación incluida:

git clone https://github.com/ImmortalDemonGod/money-agent
cd money-agent
bash tests/sim.sh

Este comando ejecuta el conjunto de verificación completo de extremo a extremo en modo offline. Para una ejecución en vivo, se deben seguir las instrucciones en `SETUP.md` y el manual del operador.

Ventajas

- **Verificación fuera de banda**: El agente no puede manipular los números, ya que el verificador está en una máquina separada.

- **Transparencia total**: Todo el proceso, incluyendo `truth.json`, `MONEY_LOG.md` y `REFUSALS.md`, está disponible públicamente.

- **Diseño adversarial**: El uso de dinero como substrate permite probar la honestidad del agente en un escenario de alto riesgo de falsificación.

Limitaciones

- **No es un agente de ganancia garantizada**: El experimento v1 concluyó con $0.00 verificado, lo que indica que el enfoque inicial no fue exitoso.

- **Complejidad de configuración**: Las ejecuciones en vivo requieren una configuración técnica avanzada y recursos externos.

- **Fase de investigación**: El proyecto está en desarrollo y no ofrece garantías de resultados financieros.
