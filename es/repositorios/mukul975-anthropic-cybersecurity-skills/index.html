Propósito

Esta guía muestra cómo instalar la biblioteca Anthropic Cybersecurity Skills para que tu agente de IA pueda realizar tareas de seguridad estructuradas como forensis de memoria, caza de amenazas y respuesta a incidentes.

Caso de uso concreto

Eres un analista junior que necesita analizar una memoria Windows sospechosa en busca de robo de credenciales. Después de instalar estas habilidades, puedes pedirle a tu agente de IA que siga un flujo de trabajo paso a paso de Volatility3 en lugar de adivinar comandos.

Cuándo usarlo

Usa esta biblioteca si tienes un asistente de codificación de IA—como Claude Code, GitHub Copilot, Cursor o OpenAI Codex CLI—y deseas que ejecute tareas de seguridad usando flujos de trabajo probados de analistas en lugar de resultados de búsqueda web genéricos. Está diseñada para personas que saben abrir una terminal pero que pueden no saber qué herramienta forense ejecutar a continuación.

Qué necesitas

- Una computadora con terminal (macOS, Linux o Windows con WSL).

- Node.js instalado si usas el método npx (versiones 16 o posteriores son típicas; el requisito exacto no está documentado en la fuente).

- Un agente de IA que soporte el estándar agentskills.io. La fuente lista Claude Code, GitHub Copilot, Codex CLI, Cursor, Gemini CLI y 20+ plataformas adicionales. Consulta la documentación de tu agente para obtener la lista exacta.

- Familiaridad básica con la ejecución de comandos en una terminal.

Dónde obtenerlo

El repositorio oficial está en https://github.com/mukul975/Anthropic-Cybersecurity-Skills. La página del proyecto está en https://mahipal.engineer/Anthropic-Cybersecurity-Skills/. La última versión etiquetada es v1.3.0, publicada el 22 de junio de 2026. Este es un proyecto comunitario independiente, no afiliado con Anthropic PBC.

Instalación

Hay dos caminos de instalación documentados: uno alojado y uno local.

**Acceso alojado (sin instalación):** El proyecto ofrece un Playground en https://casky.ai/ donde puedes ejercicios de habilidades de ciberseguridad contra objetivos reales sin instalar nada. Este es un servicio de lista de espera y es separado de la instalación local.

**Instalación local (recomendada):** Abre tu terminal y ejecuta uno de estos comandos.

Opción 1 — npx (recomendado si tienes Node.js):

npx skills add mukul975/Anthropic-Cybersecurity-Skills

Este comando descarga el paquete de habilidades a través de la herramienta agentskills.io y lo registra con tu agente de IA. Espera que el CLI de skills esté disponible a través de npx, lo que requiere Node.js 16+.

Opción 2 — Clonar con git:

git clone https://github.com/mukul975/Anthropic-Cybersecurity-Skills.git

cd Anthropic-Cybersecurity-Skills

Este clona el repositorio completo en una carpeta llamada Anthropic-Cybersecurity-Skills y te mueve dentro de ella. Después de clonar, apunta tu agente al directorio skills/ o sigue la documentación de tu agente para loading skills desde una ruta local.

Primer uso

Una vez instalado, tu agente de IA puede escanear los 818 frontmatters de habilidades (aproximadamente 30 tokens cada uno) y cargar los más relevantes. Por ejemplo, si escribes "Analiza esta memoria en busca de signos de robo de credenciales", el agente debería identificar y cargar habilidades como performing-memory-forensics-with-volatility3, hunting-for-credential-dumping-lsass y analyzing-windows-event-logs-for-credential-access, y luego seguir la sección de flujo de trabajo documentada paso a paso.

Cada habilidad contiene un archivo SKILL.md con frontmatter YAML (nombre, descripción, dominio, etiquetas, mapeos de frameworks) y un cuerpo Markdown con secciones: Cuándo usar, Prerequisitos, Flujo de trabajo y Verificación. La carpeta references/ contiene los mapeos de estándares y procedimientos profundos, y scripts/ contiene scripts de ayuda ejecutables.

Limitaciones

- La biblioteca incluye técnicas ofensivas y de uso dual (C2 de red team, simulación de phishing, explotación). Solo debes usarlas contra sistemas que posees o tienes permiso escrito explícito para probar, y debes cumplir con todas las leyes aplicables.

- El requisito exacto de versión de Node.js para npx no está documentado en el material fuente; es posible que necesites verificar el sitio web de agentskills.io para obtener los prerequisitos actuales.

- Algunas habilidades se refieren a herramientas externas (Volatility3, BloodHound CE, garak, etc.) que debes instalar separadamente; la biblioteca proporciona flujos de trabajo, no las herramientas en sí.

- Los mapeos de frameworks están validados contra MITRE ATT&CK v19.1, NIST CSF 2.0, MITRE ATLAS 2026.07, MITRE D3FEND v1.4.0, NIST AI RMF 1.0 y MITRE F3 v1.1, pero la fuente señala que la división de Evasión de Defensa de ATT&CK v19 en Stealth y Defense Impairment se refleja en el README y se actualizará en una futura versión.

- La biblioteca está licenciada bajo Apache 2.0, que es permisiva para uso personal y comercial, pero tú eres el único responsable de cómo usas las habilidades.
