Qué es

FastAPI es un framework Python para construir APIs. Utiliza anotaciones de tipos y ofrece documentación interactiva. Un punto de partida útil es una API pequeña que reciba solicitudes y devuelva datos; no necesitas convertir toda tu aplicación en servicios separados.

Para qué sirve

Puedes probar un endpoint de lectura, revisar su respuesta y utilizar la documentación generada para explorar el contrato. El ejemplo es deliberadamente pequeño: no incluye base de datos, autenticación ni pagos.

Fuentes y señales

Hemos consultado el repositorio y el tutorial oficial. No presentamos estrellas históricas como velocidad de crecimiento. Las releases y la actividad son observaciones que el pipeline puede registrar, pero no sustituyen una evaluación de calidad o seguridad.

Instalación

El tutorial recomienda un entorno virtual y la instalación del conjunto estándar. Consulta su versión mínima de Python antes de seguirlo. Estos comandos no se ejecutaron para redactar la guía.

python -m pip install "fastapi[standard]"

Primera ruta

Guarda este ejemplo en main.py y arranca el servidor de desarrollo indicado por la documentación.

from fastapi import FastAPI
app = FastAPI()
@app.get('/')
def read_root():
    return {'message': 'Hello'}
fastapi dev main.py

Verificación manual

Visita la dirección local que muestra la terminal y abre /docs. Comprueba que la respuesta coincide con tu contrato y ensaya errores de entrada en una ruta propia. La documentación interactiva no significa que tu API esté protegida.

Ventajas y límites

Los tipos y los esquemas hacen explícitas muchas expectativas. La lógica empresarial, permisos y pruebas siguen siendo responsabilidad del proyecto. Un servidor de desarrollo no es un despliegue: revisa autenticación, validación, secretos, límites, logs y manejo de errores antes de exponerlo.

Alternativas

Flask o Django pueden encajar mejor cuando ya dispones de una aplicación o necesitas otras piezas. Evalúa requisitos y experiencia del equipo antes de migrar. El repositorio indica licencia MIT; revisa también las dependencias y los servicios que añadas.

Los proyectos pertenecen a sus autores. Comprueba instrucciones y licencias oficiales antes de producción.
