Propósito

Stickman Video Director convierte un guion, un tema o un enlace web en un video animado de palitos con voz en off, subtítulos y efectos de sonido, sin necesidad de cámara ni equipo de filmación. Un caso de uso concreto es un creador de YouTube sin rostro que necesita un video explicativo de ciencia de 90 segundos en formato 16:9 y usa el Modo Autopiloto para generar un archivo de video completo a partir de un tema aproximado.

Qué es y cómo funciona

Stickman Video Director es un Skill de código abierto, lo que significa un conjunto de instrucciones que cargas en un asistente de IA en lugar de un programa tradicional que instalas con un gestor de paquetes. El repositorio oficial es kaomei/stickman-video-director en GitHub. El proyecto ofrece dos modos de producción. El Modo Director, también llamado Modo A, está dirigido a creadores que quieren controlar cada toma. El asistente de IA planea el guion gráfico, escribe indicaciones de video escena por escena y diseña señales de sonido. Luego copias esas indicaciones en un generador de video externo como Google Flow, Runway, Luma o Kling, generas los clips y los ensamblas en un editor como CapCut o Premiere. Este modo se recomienda para videos cortos, generalmente de 30 segundos a 3 minutos. El Modo Autopiloto, también llamado Modo B, está dirigido a creadores que quieren un video terminado sin ensamblar escenas ellos mismos. Le das al asistente un tema, artículo, enlace o resumen, y este planea las escenas, genera visuales y narración, agrega subtítulos y efectos de sonido, y renderiza un archivo de video completo sincronizado con la voz en off. Este modo se ejecuta dentro de agentes de IA para programación como Codex, Claude Code o Cursor, que son programas capaces de leer y escribir archivos, ejecutar comandos y usar herramientas en tu nombre. El Modo Autopiloto está orientado a videos de larga duración de 10 minutos o más, aunque también funciona para shorts y historias episódicas. Ambos modos admiten relaciones de aspecto de 9:16, 16:9 y 1:1, y puedes elegir libremente el idioma y la voz de la narración. El proyecto incluye estilos visuales numerados de A1 a A7 para el Modo Director y de B1 a B5 para el Modo Autopiloto, que van desde arte de línea blanco y negro clásico hasta escenas dibujadas a mano coloridas. Según la documentación, la generación visual pesada se maneja mediante APIs en la nube o renderizado procesal, no en la tarjeta gráfica de tu computadora local.

Cuándo usarlo

Úsalo cuando tengas un canal de YouTube sin rostro y necesites videos explicativos animados sin aparecer en cámara. Úsalo cuando quieras convertir una publicación de blog, un enlace de noticias o una idea aproximada en un video narrado con subtítulos y efectos de sonido. Usa el Modo Director cuando necesites indicaciones escena por escena para generar clips en generadores de video externos y luego editarlos tú mismo.

Qué necesitas

Necesitas una computadora con acceso a internet y un asistente de IA que pueda instalar y ejecutar el Skill. Para el Modo Director, cualquier asistente de IA conversacional compatible con Skills es suficiente. Para el Modo Autopiloto, necesitas un agente de IA para programación con acceso a archivos y terminal, como Codex, Claude Code o Cursor; la documentación no afirma que todos los asistentes funcionen igual, y señala que los resultados pueden variar entre modelos y configuraciones. No necesitas habilidades de programación ni una tarjeta gráfica de alto rango, según las preguntas frecuentes. Si quieres conectar servicios de generación de imágenes, voz o video, es posible que necesites cuentas o claves de API de proveedores externos. El README menciona ejemplos como Google Gemini, Claude, ElevenLabs, Google Flow, Runway, Luma y Kling, pero usarlos es opcional y el proyecto no requiere un proveedor específico. No se documenta ningún sistema operativo o versión de tiempo de ejecución compatible en el paquete.

Dónde conseguirlo

La ubicación oficial de descarga es el repositorio de GitHub en https://github.com/kaomei/stickman-video-director. La rama predeterminada es main. Existe una versión etiquetada como v2026.11.11.2, pero no se documenta ningún archivo de instalador independiente en los recursos de la versión. Se trata de acceso alojado: obtienes el Skill apuntando tu asistente de IA a la URL del repositorio. No hay un método de instalación local documentado, como un comando git clone o npm install.

Instalación

No se documenta ningún comando de terminal para la instalación en el README oficial ni en las notas de la versión. En su lugar, el primer paso documentado es enviar el siguiente texto a tu asistente de IA: Install this Skill for me: https://github.com/kaomei/stickman-video-director. Una vez instalado, debes pedirle al asistente que lea el archivo SKILL.md instalado de inmediato. El README recomienda comenzar con Codex para obtener resultados más cercanos a los ejemplos de la vitrina, pero esto es una recomendación, no un requisito. Como no se documenta ningún comando de instalación local, no puedes verificar una configuración local mediante un comando de terminal; dependes del asistente de IA para configurar el Skill.

Primer uso paso a paso

Abre tu asistente de IA. Si vas a usar el Modo Autopiloto, confirma que tiene acceso a archivos y terminal. Envía el texto de instalación al asistente y pídele que lea SKILL.md. Decide qué modo usar. Para el Modo Autopiloto, pega un tema, artículo, enlace o resumen y especifica la duración, la relación de aspecto, el estilo y que quieres voz en off, subtítulos y efectos de sonido. Pídele al asistente que verifique primero la configuración de generación de imágenes, voz en off y renderizado de video, y luego produzca un guion y una vista previa de 20 segundos con sonido. Aprueba el guion y la vista previa, y luego deja que el asistente construya el video completo y entregue el archivo de video terminado. Para el Modo Director, envía tu tema y solicita un tratamiento del director. Después de aprobar el tratamiento, pide indicaciones de video escena por escena. Copia cada indicación en tu generador de video externo elegido, genera los clips y termina la edición en CapCut, Premiere o tu editor preferido. Opcionalmente, puedes solicitar el Kit de Publicación y Miniatura después de confirmar el video final; este genera una imagen de portada coincidente, variantes de título, descripción, etiquetas y una pregunta de participación, pero la generación de imágenes depende de una herramienta disponible y de cualquier aprobación de costo requerida.

Errores comunes y cómo solucionarlos

La documentación no proporciona una lista de códigos de error de terminal, pero describe varias situaciones predecibles. Los resultados pueden diferir entre asistentes de IA debido a modelos, configuración de herramientas y ejecución; si tu resultado no coincide con los ejemplos de la vitrina, el proyecto recomienda usar Codex para obtener la coincidencia más cercana. En el primer uso del Modo Autopiloto, el asistente verifica la configuración requerida y te guía a través de lo que falte; si un paso falla, sigue la orientación del asistente en lugar de adivinar un comando. Si la generación de imágenes no está disponible, el asistente debería explicar la brecha y aún así entregar las partes de texto del kit de publicación. La consistencia del personaje puede ser difícil en el Modo Director al usar generación de video a partir de texto para personajes complejos; la documentación sugiere agregar una imagen de referencia de personaje de palito y reutilizarla en todos los clips. No se esperan errores de GPU local porque, según los documentos, la generación pesada no se realiza en tu hardware.

Limitaciones

No es una aplicación de escritorio o móvil independiente. El Modo Autopiloto requiere un agente de IA para programación con acceso a archivos y terminal, por lo que no funcionará en asistentes que carezcan de esas capacidades. El proyecto es gratuito, pero el uso de API de terceros para imágenes, voz o video es tu responsabilidad financiera, y los precios verificados de esos servicios no están incluidos en este paquete. La elegibilidad para monetización y la autorización de Content-ID en YouTube o TikTok no están garantizadas, según se indica en la sección del Kit de Publicación y Miniatura. Las notas de la versión indican que 200 pruebas de tiempo de ejecución sin conexión y verificaciones de regresión validan reglas de ejecución, no la calidad creativa ni la salida de proveedores en vivo. El estilo A7 aparece como próximo y no está disponible.

Alternativas y cómo se compara

En comparación con editores de video manuales como CapCut o Premiere, Stickman Video Director automatiza la planificación y el renderizado a través de un asistente de IA, pero el Modo Director aún requiere que generes clips externamente y los ensambles tú mismo. En comparación con plataformas dedicadas de video de IA como Runway, Luma, Kling o Google Flow, este proyecto agrega guion gráfico específico para palitos, ajustes de estilo predeterminados y un flujo de trabajo de autopiloto que esas plataformas no proporcionan como un Skill empaquetado. En comparación con servicios SaaS de video sin rostro basados en suscripción, este proyecto tiene licencia MIT y es gratuito para usar, aunque aún podrías pagar por las APIs de terceros que conectes. No se afirman precios específicos para las alternativas aquí.

Preguntas frecuentes

P1: ¿Es realmente gratuito al 100 por ciento? Sí. El proyecto se publica bajo la licencia MIT y es gratuito para uso personal y comercial. Solo pagas por el uso de API de terceros si decides conectar servicios como generación de imágenes, voz o video.

P2: ¿Necesito habilidades de programación? No. La documentación indica que no se requieren conocimientos de codificación ni una GPU costosa. El Modo Autopiloto se opera mediante inglés conversacional dentro de un agente de IA para programación.

P3: ¿Puedo monetizar los videos en YouTube y TikTok? El proyecto dice que sí porque el salida utiliza arcos de narración personalizados y puesta en escena visual original, pero también señala que la elegibilidad para monetización y la autorización de Content-ID no están garantizadas.

P4: ¿Necesito un guion existente? No. Puedes comenzar con una idea aproximada, un enlace, una noticia o una publicación de blog completa, y el director de IA extraerá el conflicto central y estructurará la historia.

Evaluación editorial: para quién es y para quién no es

Esta guía está dirigida a personas que abren su primera terminal y ya usan o están dispuestas a usar un asistente de IA para programación, especialmente creadores de YouTube sin rostro, educadores y narradores que quieren videos animados de palitos sin filmar. Deberías omitirlo si necesitas una aplicación tradicional instalable con interfaz gráfica, si no tienes acceso a un agente de IA para programación con acceso a archivos y terminal para el Modo Autopiloto, o si no estás dispuesto a gestionar cuentas de API de terceros y posibles costos de uso.

Licencia y precios oficiales

El proyecto tiene licencia bajo la Licencia MIT, que permite el uso gratuito, modificación, distribución y uso comercial, siempre que se mantengan el aviso de copyright original y el aviso de licencia. El proyecto en sí se describe como gratuito y de código abierto al 100 por ciento. Los precios verificados para servicios de terceros no están disponibles en este paquete; cualquier costo depende de los proveedores que elijas conectar.
