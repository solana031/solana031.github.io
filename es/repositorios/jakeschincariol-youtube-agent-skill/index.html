Descripción general y propósito

`youtube-agent-skill` es un conjunto de herramientas de código abierto bajo licencia MIT que incluye once habilidades para Claude, orientadas a optimizar el flujo de trabajo de creación y estrategia de contenido en YouTube. El paquete permite generar guiones basados en 21 fórmulas de enganche, evaluar títulos y miniaturas de forma conjunta, construir listas de decisiones de edición a partir de transcripciones, analizar datos de retención de audiencia, extraer vídeos cortos (Shorts) y estudiar métricas de viralidad en nichos específicos.

Requisitos y configuración de instalación

El proyecto requiere un entorno con Python 3 estándar (sin dependencias externas) para ejecutar sus seis herramientas analíticas por línea de comandos. Los usuarios de Claude Code pueden instalar la suite de forma global o local.

Para clonar e instalar globalmente en Claude Code:

git clone https://github.com/Jakeschincariol/youtube-agent-skill.git
cp -r youtube-agent-skill/skills/yt-* ~/.claude/skills/

También es posible instalarlo mediante el sistema de complementos:

/plugin marketplace add Jakeschincariol/youtube-agent-skill
/plugin install youtube-agent

En entornos sin Claude Code, se puede pegar cualquier archivo `SKILL.md` al inicio de una sesión de chat para activarlo como modo de trabajo, aunque en ese escenario no se ejecutan las herramientas en Python. Para personalizar el tono de voz de los textos, se debe copiar el archivo `templates/voice.md` a la ruta `~/.claude/youtube/voice.md` o solicitar a Claude que lo genere analizando guiones o vídeos previos.

Uso y herramientas autónomas

La suite incluye once comandos principales como `/yt-script`, `/yt-package`, `/yt-edit`, `/yt-comment`, `/yt-plan`, `/yt-viral`, `/yt-retention`, `/yt-shorts`, `/yt-seo`, `/yt-chapters` y `/yt-audit`. Además, cuenta con seis herramientas ejecutables en Python 3 sin dependencias adicionales:

python3 skills/yt-script/hookscore.py --hook "one line"
python3 skills/yt-package/title.py --title "..." --thumb "..."
python3 skills/yt-edit/deadair.py transcript.srt
python3 skills/yt-chapters/chapters.py transcript.srt
python3 skills/yt-retention/retention.py retention.csv
python3 skills/yt-viral/swipe.py collected.json --min 2.0

Ventajas, limitaciones y comparación

A diferencia de alternativas comerciales SaaS que requieren pagos de suscripción o claves API, `youtube-agent-skill` se distribuye gratuitamente bajo la licencia MIT. Entre sus consideraciones técnicas destacan:

- **Sin publicación automática:** No sube contenido directamente a la plataforma; genera bloques de texto formateados para revisión y copia manual.

- **Puntuación heurística:** El script `hookscore.py` ofrece un análisis heurístico calibrado sobre 74 ganchos de vídeo, por lo que una puntuación alta no garantiza un volumen de visualizaciones determinado.

- **Datos públicos:** `/yt-viral` analiza únicamente listas públicas sin requerir inicio de sesión ni realizar raspado (scraping) privado con credenciales de usuario.

Precio verificado: Es software libre y completamente gratuito bajo la licencia MIT.
