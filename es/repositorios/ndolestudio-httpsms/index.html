Propósito y Visión General

httpSMS es un servicio diseñado para permitir que los usuarios utilicen un teléfono Android físico como una pasarela SMS (SMS Gateway) programática. El proyecto resuelve la necesidad de interactuar con SMS mediante una interfaz HTTP simple, lo cual resulta útil en regiones donde la adquisición de números virtuales mediante plataformas comerciales tradicionales resulta compleja o inaccesible. Mediante solicitudes HTTP, el sistema activa el dispositivo móvil para enviar mensajes, y reenvía los SMS recibidos a un punto final de webhook configurado.

Requisitos Documentados

Para autohospedar el sistema utilizando Docker y ponerlo en marcha localmente o en un servidor propio, se requiere cumplir con los siguientes elementos:

- Un proyecto en Firebase para la mensajería en la nube (Cloud Messaging), con el SDK web configurado y credenciales de cuenta de servicio (`firebase-credentials.json` y `google-services.json`).

- Un servidor SMTP configurado para el envío de alertas por correo electrónico.

- Widgets de Cloudflare Turnstile configurados (claves de sitio y clave secreta) para proteger las rutas de búsqueda.

- Docker y Docker Compose para levantar la pila completa que incluye la API en Go, la interfaz web en Nuxt y Vuetify, la base de datos CockroachDB o PostgreSQL y Redis.

Instalación y Configuración

El repositorio oficial proporciona instrucciones claras para realizar el despliegue mediante Docker. Los pasos documentados consisten en clonar el repositorio, configurar los archivos de entorno y ejecutar el despliegue de contenedores:

git clone https://github.com/NdoleStudio/httpsms.git
cp web/.env.docker web/.env
cp api/.env.docker api/.env
docker compose up --build

Asimismo, es necesario instalar la aplicación nativa para Android disponible en el repositorio de lanzamientos (`HttpSms.apk`) en un dispositivo móvil con la configuración de Firebase correspondiente.

Uso y Ejemplo de Código

La API permite interactuar con los mensajes de forma programática. A continuación se muestra un ejemplo documentado en Go para el envío de un mensaje de texto mediante los clientes oficiales:

client := htpsms.New(htpsms.WithAPIKey(/* API Key from https://httpsms.com/settings */))

client.Messages.Send(context.Background(), &httpsms.MessageSendParams{
    Content: "This is a sample text message",
    From:    "+18005550199",
    To:      "+18005550100",
})

Ventajas y Características

- **Cifrado de extremo a extremo:** Los mensajes pueden cifrarse mediante AES-256 de forma que solo residan en el teléfono móvil, manteniendo la privacidad frente al servidor.

- **Control de flujo (Back Pressure):** Permite configurar límites de envío por minuto para evitar saturar o infringir las políticas de la pasarela Android.

- **Caducidad de mensajes:** Posibilidad de definir tiempos de expiración para los mensajes que no alcancen a entregarse de inmediato.

- **Soporte de Webhooks:** Permite reenviar los mensajes entrantes a cualquier servidor backend de forma automatizada.

Limitaciones

- Depende estrictamente de la conectividad y disponibilidad de un teléfono Android físico operativo.

- Requiere una configuración inicial compleja que abarca Firebase, SMTP y Cloudflare Turnstile en despliegues autohospedados.

Comparativa y Alternativas

Frente a servicios comerciales centralizados de pasarelas SMS (como Twilio o proveedores tradicionales de números virtuales), httpSMS ofrece una alternativa autohospedable que utiliza la infraestructura móvil propia del usuario. Esto elimina la dependencia de tarifas corporativas recurrentes por cada número virtual, aunque transfiere la responsabilidad operativa del hardware móvil y del mantenimiento del servidor al propio usuario.
