Explora html-anime, una herramienta que transforma prompts de escenas en hojas de planos para que agentes de codificación dibujen animaciones puramente en HTML, sin utilizar modelos de video tradicionales.

Propósito

El proyecto **html-anime** permite transformar un prompt o descripción de escena en una hoja de planos detallada (*shot sheet*). En lugar de recurrir a modelos de video tradicionales, el flujo de trabajo delega la creación visual a un agente de codificación (como Claude, Codex, Cursor o Grok). Este agente interpreta la hoja y dibuja los fotogramas utilizando código HTML puro y el renderizador HyperFrames.

Requisitos y Configuración

Para poner en marcha el repositorio localmente, asegúrate de contar con Git y Node.js instalados en tu sistema. La configuración inicial se realiza mediante comandos básicos de clonación de repositorio.

git clone https://github.com/blixvip/html-anime.git
cd html-anime

Además, dado que el sistema requiere servir los archivos localmente para que funcionen correctamente en el navegador, puedes utilizar un servidor estático simple:

python -m http.server

*(Nota: Abrir `index.html` directamente como archivo local impedirá que las hojas funcionen correctamente hasta que la carpeta sea servida a través de un servidor HTTP).* También puedes compilar una hoja directamente utilizando Node.js sin dependencias externas mediante el script de compilación incluido.

Uso

Puedes generar hojas de planos directamente desde el navegador en la página oficial o usar Node.js para compilar una sesión mediante programación:

import { compileBrief } from "./harness/compile.js";

const sheet = compileBrief({
  logline: "On a roof in the rain, a red moon opens and a line of light falls.",
  seconds: 8,
  aspect: "16:9",
  script: "indigo",
  dialogue: "The rain hid the sound of the blade.",
});
console.log(sheet.ok ? sheet.markdown : sheet.error);

Para probar la integridad del código, el repositorio incluye una suite de pruebas automatizadas:

npm test

Y para renderizar la película de referencia:

cd films/roof
npx hyperframes preview

Ventajas

- **Sin modelos de video:** Evita la pesada infraestructura de IA generativa de video convencional.

- **Control estricto por reglas:** Los agentes deben seguir pautas estrictas sobre tiempos de planos, uso de fotogramas, paletas de colores restringidas y fidelidad de los diálogos.

- **Integración con múltiples agentes:** Compatible de forma nativa con configuraciones para Claude Code, Codex, Cursor y Grok.

Limitaciones

- Requiere que la carpeta del proyecto sea servida mediante un servidor local para que las hojas de planos se ejecuten correctamente.

- Depende de las capacidades del agente de codificación utilizado para interpretar correctamente el diseño HTML y las reglas de animación.

- Los tiempos de duración de las tomas se limitan estrictamente a bloques predefinidos (8, 12 o 20 segundos).

Comparativa Editorial y Alternativas

Frente a los generadores de video basados en difusión que devuelven archivos multimedia opacos, este enfoque prioriza la transparencia del código fuente al construir animaciones vectoriales y HTML estilizadas. Como alternativa a herramientas como Sora o Runway, que generan píxeles directamente mediante redes neuronales masivas, html-anime ofrece un control modular y programático sobre el arte final mediante agentes de desarrollo de software.
