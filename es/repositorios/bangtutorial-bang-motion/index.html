Bang Motion: Convierte tu Agente de IA en Diseñador de Movimiento

Guía oficial y habilidad de agente para Bang Motion (bangtutorial/bang-motion), una herramienta que transforma prompts en gráficos en movimiento de calidad profesional en un solo archivo index.html.

Propósito

**Bang Motion** es una habilidad de agente para asistentes de código de Inteligencia Artificial que actúa como diseñador de movimiento. En lugar de generar diapositivas estáticas y aburridas con fundidos básicos, este proyecto produce animaciones continuas, cámaras dinámicas y tipografía cinética empaquetadas en un único archivo `index.html`. Funciona de forma fluida con herramientas como Claude Code, Codex, Gemini CLI y Cursor.

El proyecto aborda el problema clásico de que la IA genere animaciones rígidas tipo PowerPoint, aplicando reglas estrictas de diseño de movimiento, menús de conceptos estructurales y estilos basados en la marca.

Requisitos

Según la documentación oficial, los requisitos varían según el uso:

- **Visualización básica:** Un navegador web moderno con acceso a internet para cargar dependencias como GSAP y fuentes desde una CDN.

- **Verificación automática de fotogramas:** Node.js junto con Puppeteer (opcional, mediante `scripts/snap.mjs`).

- **Exportación a MP4:** Node.js, Puppeteer y FFmpeg (opcional, mediante `scripts/export-frames.mjs`).

- **Sincronización de voz:** FFmpeg o el script local `scripts/vo-pauses.html` para detectar pausas en el navegador.

No se requiere ejecutar `npm install` para reproducir el resultado final.

Instalación

La instalación se puede realizar como un plugin para Claude Code o mediante clonación manual del repositorio oficial de GitHub.

Como plugin de Claude Code:

/plugin marketplace add bangtutorial/bang-motion
/plugin install bang-motion@bang-motion

Método manual para cualquier agente:

git clone https://github.com/bangtutorial/bang-motion

Uso

El flujo de trabajo recomendado consta de los siguientes pasos:

1. Proporcionar un prompt inicial indicando el producto, logotipo, audiencia, duración y relación de aspecto.

2. Revisar el informe de estilo generado por el agente, el cual ofrece tres candidatos conceptuales y una paleta de colores justificada.

3. Añadir activos propios o permitir que el agente genere recursos visuales mediante un protocolo de imágenes (MCP).

4. Construir el archivo `index.html` optimizado.

5. Revisar y depurar utilizando el parámetro `?debug=1` en el navegador.

Ejemplos de prompts soportados:

Make a 30-second opener for my note-taking app. Logo and screenshots attached.
Build a 45-second product tour of our HR dashboard in the "product tour with claims" style, 16:9.

Ventajas

- Generación de animaciones fluidas basadas en código web nativo y GSAP.

- Salida en un único archivo `index.html` independiente y fácil de compartir.

- Previene la monotonía visual gracias a múltiples estilos de diseño, conceptos de apertura y familias de renderizado.

- Compatible con múltiples agentes de IA populares.

Limitaciones

- Requiere el uso de herramientas externas adicionales (como Puppeteer o FFmpeg) si se desea exportar de forma automatizada a formato MP4.

- Las vistas previas avanzadas o la sincronización de voz dependen de la correcta ejecución de scripts de Node o del navegador.

- La calidad y adecuación del resultado final dependen en gran medida de la precisión del prompt inicial y de la correcta provisión de la identidad de marca.

Comparativa y Alternativas

Frente a enfoques tradicionales que generan presentaciones estáticas basadas en diapositivas o secuencias de vídeo preconfiguradas sin interactividad, Bang Motion ofrece una arquitectura determinista basada en código HTML, CSS y SVG. Otras alternativas incluyen herramientas propietarias de diseño como After Effects, aunque Bang Motion integra un puente MCP específico para conectar directamente con dicho software si se prefiere una construcción híbrida.
