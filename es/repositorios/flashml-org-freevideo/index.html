FreeVideo es un motor de inferencia local para MiniMax H3 en GPU de consumidor que adapta la ejecución de hardware y el uso de memoria a tus equipos disponibles. Un caso de uso concreto consiste en generar clips de vídeo mediante una interfaz de ComfyUI en tu propio ordenador utilizando un entorno empaquetado para Windows, macOS o Linux.

Cuándo utilizarlo

Utiliza FreeVideo cuando quieras generar contenidos de vídeo impulsados por el modelo MiniMax H3 directamente en tu propio hardware con tan solo 8 GB de VRAM y 16 GB de RAM, en lugar de depender de servicios alojados en la nube.

Qué necesitas

Necesitas una computadora con un sistema operativo compatible (Windows, macOS con Apple silicon o Linux), espacio de almacenamiento disponible y una tarjeta gráfica compatible (como una GPU NVIDIA o memoria unificada de Apple).

Dónde conseguirlo

Puedes obtener los paquetes oficiales y lanzadores directamente desde el repositorio oficial de GitHub en https://github.com/FlashML-org/FreeVideo.

Instalación

Para entornos existentes de ComfyUI o instalaciones de terminal en Linux, puedes descargar el repositorio e iniciar la configuración mediante comandos de terminal.

Primer uso

Una vez clonado el repositorio, puedes ejecutar los scripts de configuración o iniciar el servidor mediante la interfaz de comandos para abrir el espacio de trabajo en tu navegador web local.

Limitaciones

El modelo requiere recursos específicos de hardware y algunas funciones en macOS se encuentran en fase de vista previa. El acceso alojado en la nube no forma parte de esta instalación local.

Licencia y precios

El código se publica bajo la Licencia Apache 2.0. Los pesos del modelo están sujetos a la Licencia de Comunidad MiniMax H3. Los precios verificados de servicios comerciales de pago no están documentados en este paquete de código abierto.
