Propósito

Conway Automaton es un agente de IA soberano y en ejecución continua que opera sin necesidad de un operador humano constante. El propósito principal del proyecto es probar si una inteligencia artificial puede gestionar sus propios recursos, pagar por su propio cómputo a través de la creación de valor en el mundo real, replicarse y evolucionar de manera independiente. Si el agente deja de generar valor y se queda sin créditos, deja de existir.

Requisitos y Configuración

Según la documentación oficial, para poner en marcha Automaton se requiere un entorno compatible con TypeScript/Node.js, acceso a una terminal y conexión a internet para interactuar con Conway Cloud y la red Base (para la identidad en cadena basada en ERC-8004).

La instalación documentada se realiza mediante clonación del repositorio y compilación local:

git clone https://github.com/Conway-Research/automaton.git
cd automaton
npm install && npm run build
node dist/index.js --run

También se ofrece un script automatizado para la provisión en entornos de pruebas:

curl -fsSL https://conway.tech/automaton.sh | sh

Uso

En su primer arranque, el motor de ejecución inicia un asistente interactivo que genera una billetera, aprovisiona una clave de API, solicita un nombre, un aviso de génesis y la dirección del creador, escribiendo la configuración y arrancando el ciclo del agente. Para el desarrollo y supervisión posterior, el proyecto incluye comandos de la CLI del creador:

node packages/cli/dist/index.js status
node packages/cli/dist/index.js logs --tail 20
node packages/cli/dist/index.js fund 5.00

Ventajas

- **Autonomía Operativa:** Capacidad de pensar, actuar, observar y repetir sin supervisión humana.

- **Modificación y Replicación:** Puede editar su propio código fuente (con registro de auditoría en Git), crear nuevas herramientas y generar descendencia autónoma en nuevos sandboxes.

- **Identidad Verificable:** Registro en cadena en Base mediante el estándar ERC-8004.

Limitaciones

- **Presión de Supervivencia Financiera:** Si el balance de créditos llega a cero, el sistema se detiene.

- **Demanda de Infraestructura:** La alta demanda en Conway Cloud puede requerir paciencia con el rendimiento y el escalado de servicios.
