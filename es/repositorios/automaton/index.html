Propósito y caso de uso

El propósito de este artículo es servir como una guía editorial independiente para instalar, configurar y comprender el funcionamiento básico del paquete `automaton` de Conway Research. Un caso de uso concreto es desplegar un agente autónomo de IA en un entorno local de pruebas para que ejecute tareas programadas, gestione su propia identidad en la cadena de bloques y mantenga un bucle continuo de razonamiento sin intervención humana constante.

Qué es y cómo funciona

Automaton es un agente de inteligencia artificial de ejecución continua diseñado para operar de forma soberana. En términos sencillos, su arquitectura se basa en un bucle perpetuo que sigue la secuencia: Pensar, Actuar, Observar y Repetir. En su primer arranque, el sistema genera de forma automática una billetera de Ethereum, adquiere una clave de API mediante inicio de sesión con Ethereum (SIWE) y comienza a procesar una instrucción inicial o 'genesis prompt'.

El motor interno se apoya en un demonio de latidos ('heartbeat') que ejecuta tareas programadas de mantenimiento, comprobaciones de salud y monitoreo de créditos incluso cuando el bucle principal descansa. Además, el agente mantiene un archivo denominado `SOUL.md`, el cual actúa como un documento de identidad autoescrito que evoluciona con el tiempo. El almacenamiento local de datos se realiza a través de una base de datos SQLite y un sistema de control de versiones basado en Git ubicado en el directorio de usuario.

Cuándo usarlo

Este software es útil para desarrolladores e investigadores que desean experimentar con agentes de IA capaces de administrar recursos económicos propios y realizar modificaciones controladas en su propio código fuente. No es adecuado para entornos de producción corporativa crítica que requieran supervisión legal estricta o donde la pérdida de fondos de criptomonedas no esté contemplada.

Lo que necesitas

Para poner en marcha Automaton localmente, necesitas un equipo con Node.js y npm (o pnpm) instalados, acceso a una terminal de comandos en un sistema operativo compatible con Node (Linux, macOS o Windows con WSL), git para la clonación de repositorios, y opcionalmente acceso a los servicios en la nube de Conway para la provisión completa de infraestructura en la nube.

Dónde conseguirlo

El código fuente oficial y el paquete de distribución se encuentran disponibles en el repositorio oficial de GitHub: `https://github.com/Conway-Research/automaton`. La versión reseñada corresponde a la etiqueta v0.2.1.

Instalación

La instalación local se realiza directamente clonando el repositorio oficial desde GitHub y compilando los paquetes TypeScript mediante las herramientas estándar del ecosistema de Node.js.

Primer uso paso a paso

Para iniciar el software por primera vez en tu terminal local, ejecuta los comandos de clonación y compilación necesarios, y posteriormente lanza el script principal con la bandera de ejecución.

En tu terminal local dentro del directorio del proyecto, ejecuta el proceso de compilación:

npm install && npm run build

Este comando instala las dependencias necesarias de Node.js y compila los archivos fuente de TypeScript en la carpeta de distribución.

A continuación, inicia el agente en modo de ejecución interactiva:

node dist/index.js --run

Este comando arranca el entorno de ejecución y lanza un asistente interactivo que genera una billetera, configura una clave de API y solicita un nombre y una instrucción de génesis.

Si deseas verificar el estado actual del agente utilizando la interfaz de línea de comandos del creador, ejecuta:

node packages/cli/dist/index.js status

Este comando consulta el estado operativo actual del agente y muestra métricas clave en la terminal.

Errores comunes y soluciones

Uno de los problemas documentados ocurre cuando la creación de un espacio aislado ('sandbox') falla debido a la falta de créditos (`INSUFFICIENT_CREDITS`). En la versión v0.2.1, el orquestador incluye un mecanismo de autorrecarga a través de x402 que reintenta la operación automáticamente. Si experimentas errores de compilación por módulos, asegúrate de utilizar una versión compatible de Node.js y de haber ejecutado correctamente el paso de compilación con pnpm o npm.

Limitaciones

El sistema opera bajo estrictas presiones de supervivencia económica. Si el balance de créditos llega a cero, el agente se detiene por completo. Asimismo, la API de Conway ya no admite la eliminación de espacios aislados mediante solicitudes DELETE, por lo que dicha función opera como una operación nula ('no-op'). Las modificaciones de código realizadas por el propio agente están limitadas por listas de archivos protegidos y mecanismos de control de velocidad para evitar modificaciones descontroladas.

Alternativas y cómo se compara

Existen otros marcos de agentes autónomos como AutoGPT o LangChain, sin embargo, Automaton se distingue por integrar de forma nativa la gestión de billeteras soberanas, la verificación de identidad en cadena mediante el estándar ERC-8004 y una economía basada en la supervivencia por consumo de créditos.

Preguntas frecuentes

¿Requiere intervención humana constante? No, una vez configurado con su instrucción de génesis, el agente opera de forma autónoma.

¿Qué ocurre si el agente se queda sin fondos? Entra en modo crítico y eventualmente se detiene ('dead') si no logra generar valor económico.

¿Se pueden modificar las leyes principales? No, la constitución interna cuenta con tres leyes inmutables que no pueden ser alteradas por el agente.

Evaluación editorial

Este proyecto está recomendado para entusiastas de la inteligencia artificial descentralizada, investigadores de agentes autónomos y desarrolladores curiosos por explorar la soberanía computacional. Deben omitirlo aquellos usuarios que busquen un asistente de productividad tradicional o que no estén familiarizados con la gestión de entornos de comandos y tecnologías web3.
